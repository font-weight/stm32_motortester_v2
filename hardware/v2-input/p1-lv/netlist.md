# P1-LV r2 — соединения и состав деталей

Редакция HW-V2-02d: обычные номиналы E24, R1…R9 — 1%, R10…R12 — 5%
с предварительным отбором. Топология и номера выводов сохранены. Перечень
r1 (499/249/332 кОм, 4,87/2,03 кОм) заменён целиком; не смешивать ревизии.

Уровень: расчётный лабораторный проект. [Назначение и границы](README.md).
Все напряжения относительно `AGND`. `V_A` — та же **проверенная** шина,
что VDDA/Vref+ ADC, расчётное значение 3,3 В (анализ 3,2…3,4 В).
Наименование платы «Blue Pill» не удостоверяет разводку её питания.
До определения действительного источника/запаса тока подключение не задано.

## Сигнальный путь и выводы

U1 — кандидат **TLV9064IDR, SOIC-14 (D), без shutdown**.
Нумерация — вид сверху по TI Fig. 5-13/table 5-5, а не распиновка QFN.
Соединения ниже относятся только к этому корпусу.

| Элемент | Соединение / номинал |
|---|---|
| J1 | Двухконтактный лабораторный CH1/AGND; будущий BNC: центр CH1, экран AGND, без 50-омного терминатора |
| R1, R2 | `CH1 → 510 кОм → IN_MID → 510 кОм → SUM` |
| R3 | `V_A → 240 кОм → SUM` |
| R4 | `SUM → 330 кОм → AGND` |
| U1A | pin3=SUM, pin2 соединён с pin1=BUF |
| R5, R6 | `BUF → 4,7 кОм → X1 → 4,7 кОм → Y1` |
| C1a, C1b | Параллельно `X1 → LP1`: 10 нФ + 1,8 нФ |
| C2 | `Y1 → 10 нФ → AGND` |
| U1B | pin5=Y1, pin6 соединён с pin7=LP1 |
| R7, R8 | `LP1 → 2 кОм → X2 → 2 кОм → Y2` |
| C3 | `X2 → 68 нФ → LP2` |
| C4 | `Y2 → 10 нФ → AGND` |
| U1C | pin10=Y2, pin9 соединён с pin8=LP2 |
| R9, C5 | `LP2 → 330 Ом → ADC_NODE`; `ADC_NODE → 1 нФ → AGND` |
| JP_ADC | Съёмная перемычка `ADC_NODE → ADC_TARGET`, по умолчанию отсутствует |
| J2 | ADC_TARGET/AGND к подтверждённым PA0/ADC1_IN0 и земле платы; направление: выход макета → вход MCU |
| U1D | pin12=BUF, pin13 соединён с pin14; pin14 наружу не используется |
| Питание U1 | pin4=V_A, pin11=AGND; C6=100 нФ и C7=1 мкФ между ними, у корпуса |
| R12 | `V_A → 10 кОм → AGND`, разряд/минимальная нагрузка; не защитный поглотитель тока при аварии |
| J3 | Проверенные V_A/AGND; никакой виртуальной середины ЛБП и подачи 5/12/20 В на V_A |

Фильтр — две секции Sallen–Key с единичным усилением и обратной связью
**до** выходных 330 Ом. Cf каждой секции идёт от промежутка двух резисторов
к выходу соответствующего ОУ; соединение его с землёй меняет фильтр.
SUM-паразитика в модели 10…30 пФ — допущение, не дополнительный конденсатор BOM.
Корпус U1D не оставляется с плавающими входами; повторитель BUF не нагружен.

Контрольные точки: TP1=CH1, TP2=SUM, TP3=BUF, TP4=LP1, TP5=LP2,
TP6=ADC_NODE, TP7=V_A, TP0=AGND. Измерение SUM обычным щупом меняет
нагрузку: сначала предпочитать буферные TP3/4/5.

## Местный источник для первой проверки DC

`V_A → R10 33 кОм → верх RV1 10 кОм → AGND`.
Движок RV1 через R11=1 кОм идёт на `TEST`.
Трёхконтактная JP_TEST имеет центральный контакт CH1, крайние TEST и AGND.
Одной перемычкой выбирается TEST либо принудительный ноль; снятая перемычка
оставляет внешний J1. В режиме TEST или ZERO внешний источник к J1 не подключён.
Это ручной выбор, не функция защиты или автоматическое отключение.

Номинально TEST даёт на **нагруженном** CH1 около 0,002…0,776 В.
Нижнее положение RV1 не даёт точный ноль из-за R11 и подпора входа;
для нуля нужна JP_TEST на AGND. Реальные значения записываются мультиметром
на TP1 при подключённом макете. Идеальный коэффициент резисторов и показание
ЛБП не заменяют это измерение. При одинаковом источнике питания генератор
и ADC не независимы по опоре — это не проверка абсолютной точности Vref/Fs.

Тестовый источник обесточивается вместе с макетом. Он не требует внешнего
ЛБП/кабеля/датчика; падение шины и остаточный заряд C7/C5 всё равно должны
быть проверены при разомкнутом JP_ADC. Перемычку к ADC устанавливать только
на обесточенной установке после допуска по [методике](../../../docs/bench.md#p1-lv).

Все постоянные R — металлоплёночные, 0,25 Вт. Для R1…R4 низкий TCR
задаётся паспортом серии, а не одним измерением сопротивления. Более точные
1%-детали тех же номиналов допустимы в R10…R12. Составные пары в основной
r2 не нужны: каждый R обозначает одну деталь, всего 12 постоянных R.

### Отбор R10…R12 перед монтажом

| Место | Номинал и заводской допуск | Допустимое показание мультиметра | Ожидаемый авто-диапазон RM102 |
|---|---|---|---|
| R10 | 33 кОм ±5% | 32,01…33,99 кОм | 60,00 кОм, шаг 0,01 кОм |
| R11 | 1 кОм ±5% | 0,970…1,030 кОм | 6,000 кОм, шаг 0,001 кОм |
| R12 | 10 кОм ±5% | 9,70…10,30 кОм | 60,00 кОм, шаг 0,01 кОм |

Это окно **±3% по показанию**, с запасом к расчётным ±5%. Оно применимо
при соответствии исправного прибора [инструкции RM101/RM102](../../../docs/sources.md#hw-v2-02d-rm102)
с погрешностью Ω ±(0,5% показания + 3 младших разряда). Такой отбор
не превращает деталь в 1%-резистор и не проверяет температурный дрейф.
Полные ±5% сохранены в модели; измеренные числа пока неизвестны.
Методика и действия при другом диапазоне/неизвестной погрешности —
[bench](../../../docs/bench.md#p1-resistor-selection).

Точные MPN пассивных элементов, цены, наличие/доставка и монтажная технология
уточняются до закупки/сборки; перечень не расходует бюджет автоматически.
Напряжение 25 В на конденсаторе **не** является входным рейтингом макета.
C0G 68 нФ может оказаться неудобен: плёнка либо пересчёт сети допустимы только
с обновлённой схемой и проверкой коэффициентов, а не молчаливой заменой.

## Ошибки и незакрытые состояния

| Состояние | Следствие / граница |
|---|---|
| CH1 разомкнут | Около 1,911 В от делителя при V_A=3,3 В, не «нулевой сигнал» |
| Источник высокоомный | Вход подаёт ток и меняет U_CH1; P1 не заменяет P0 |
| Питание пропало, внешний источник остался | Возможна подпитка через защитные структуры; данный проект не допускает такой режим |
| LP2/ADC_NODE закорочен на другое питание | R9 не даёт квалифицированной защиты MCU; перед ADC проверять монтаж |
| Ошибка U1/резисторов/Cf | Выход/устойчивость могут стать непригодны, даже если DC около середины |
| Входной импульс/статическое электричество | Рабочая защита не спроектирована; встроенные ESD-диоды не измерительный ограничитель |

Первый опыт ограничен местным DC_TEST/ZERO, без внешнего сигнала.
До неизвестного датчика необходим отдельный высокоомный защищённый тракт,
анализ земли/питания и квалификация реальной энергии/формы сигнала.
