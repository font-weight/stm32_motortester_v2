# P1-LV r2 — расчётный лабораторный вход без датчика

Это **проект для последующей проверки**, не готовый прибор и не инструкция
подключать внешнее напряжение к STM32. Датчик и кабель для этого этапа не нужны.
Фактическая приёмка и следующие действия — [progress](../../../docs/progress.md).

P1-LV позволяет исследовать DC-смещение, фильтр и цепочку «напряжение на CH1 →
ADC → файл». Один фиксированный коэффициент и питание от одной проверенной
шины около 3,3 В уменьшают число неизвестных. U1 и ADC должны иметь общую
проверенную шину; отдельные выходы ЛБП и USB не соединяются параллельно.
Предложен местный источник небольшого DC-уровня от той же шины.

**P1-LV не заменяет P0 для ёмкостного датчика.** Его входное сопротивление
около 1,16 МОм и DC-подпор заметно меняют сигнал пассивного датчика.
P0 с 10/100 МОм остаётся отдельным исследуемым вариантом. Вход P1-LV не имеет
квалифицированной защиты от неизвестных импульсов или выключенного питания.

## Состав проекта

- [Учебное руководство Word](../../../docs/guides/motortester-input-guide-ru.docx) —
  принципы схем, причины выбора и карта соединений с пояснениями.
- [Понятный список материалов](materials-ru.md) — что искать в магазине,
  сколько штук нужно, какие корпуса/допуски важны и что уже есть.
- [netlist.md](netlist.md) — электрические соединения, выводы SOIC-14 и BOM.
- [schematic.svg](schematic.svg) — читаемый расчётный чертёж тех же сетей.
- [model.py](model.py) — воспроизводимая арифметика без сторонних библиотек;
  [calculations.json](calculations.json) — численный результат.
- [model-report.png](model-report.png) — графики идеальных моделей;
  [plot.py](plot.py) воспроизводит их при наличии matplotlib.
- [measurement-template.csv](measurement-template.csv) — пустой журнал будущего опыта,
  без вымышленных измерений.

Модель содержит идеальные ОУ, RC и допуски. Она не рассчитывает реальные
пуск/устойчивость/перегрузку TLV9064. Чертёж SVG не заменяет CAD/PCB/проверку ERC.
Первичные основания — [источники](../../../docs/sources.md#v2-hw-12);
Ревизия r2 использует E24: R1…R9 — 1%, R10…R12 — 5% с отбором.
Прежняя r1 сохранена в истории Git; смешивать её номиналы с r2 не следует.
Формулы — [архитектура](../../../docs/architecture.md#hw-v2-02-p1-lv);
порядок будущего опыта — [методика](../../../docs/bench.md#p1-lv).

## Воспроизведение из корня V2

Расчёт и SVG-чертёж требуют Python ≥3.10, без библиотек:

```powershell
.\.venv\Scripts\python.exe -B hardware\v2-input\p1-lv\model.py
.\.venv\Scripts\python.exe -B hardware\v2-input\p1-lv\schematic.py
```

Для PNG схемы добавить `--png` к последней команде; используется уже
установленный в среде приложения PySide6. Для научных графиков нужна
matplotlib 3.10.8. Чтобы не менять зависимости приложения:

```powershell
py -3 -m venv build\p1-plot-env
.\build\p1-plot-env\Scripts\python.exe -m pip install matplotlib==3.10.8
.\build\p1-plot-env\Scripts\python.exe -B hardware\v2-input\p1-lv\plot.py
```

Генераторы перезаписывают только свои расчётные JSON/SVG/PNG в этой папке.
Ни одна команда не обращается к COM/ST-Link. `measurement-template.csv`
остаётся пустым до реальных измерений; копировать его для нового опыта.

## Что можно готовить сейчас

1. Сверить корпус ОУ, доступные номиналы и возможности пайки; цены/продавцы
   проверяются перед покупкой. Обычный LM358 не является согласованной заменой.
2. Установить точную модель/инструкцию мультиметра и измерителя C. Сообщение
   пользователя «rich-meters 102» пока не устанавливает точность его экземпляра.
3. Перед сборкой перенести соединения в электрическую CAD-схему, проверить
   выводы, ERC и будущий монтаж. Короткий аналоговый узел и развязка питания
   нужны даже при невысокой полезной полосе: сам ОУ имеет широкую полосу.
4. До подключения ADC проверить питание/выход мультиметром, затем переходные
   процессы осциллографом. Мультиметр не исключает самовозбуждение.

Готовить собственный датчик можно после фиксации требований к его интерфейсу:
геометрия/ёмкость электрода, кабель/экран, входная нагрузка, допустимые условия
и изоляция. Подбор только по размеру красивой осциллограммы не определяет
качество измерения. Сейчас эти параметры остаются TBD.
