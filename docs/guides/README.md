# Учебное руководство по аналоговому входу

[Руководство Word](motortester-input-guide-ru.docx) объясняет P1-LV, P0,
исторические A/B, усилители, смещение, фильтры, соединения и порядок будущих
работ. [Текстовый источник](input-explained-ru.md) предназначен для правок
в репозитории; [генератор Word](build_guide.py) сохраняет картинки внутри файла.
Основные электрические сведения остаются в netlist/architecture/bench;
руководство их объясняет, а не вводит новый аппаратный допуск.

Редакция 3 описывает **P1-LV r3**: TLV9064QDRQ1, все постоянные R1–R12
1% и 0,25 Вт, C1a/C1b/C2/C3/C4 MKP 5% 50 В. C5 остаётся C0G/NP0 0805,
расчётный допуск 5%; C6/C7 — X7R для питания. Разделы 6а–6г содержат
объяснение выбора и полный перечень электронных деталей, разъёмов и монтажа.
Раздел 10 включает весь электрический чертёж в шести читаемых фрагментах
и полную карту соединений. Word самодостаточен для чтения без чата.
Значения P0 и исторических A/B остаются собственными; их списки не смешиваются.

Для воспроизведения нужен Python с python-docx и Pillow из встроенной среды
документов Codex; путь к среде определять через load_workspace_dependencies.
Из корня репозитория выполнить этим интерпретатором:

```text
docs/guide-assets/generate.py
docs/guides/build_guide.py
```

До генерации иллюстраций обновить `hardware/v2-input/p1-lv/schematic.png`
штатным генератором схемы: шесть фрагментов Word берутся из этого файла.
Изменение размеров схемы требует пересмотреть координаты фрагментов в
`generate.py`; контроль размера предотвращает тихое обрезание новой схемы.

Затем штатный render_docx.py навыка documents создаёт страницы для визуальной
проверки. Его текущая реализация на Windows использует установленный native
LibreOffice; Poppler берётся из runtime. Сам генератор Word не запускает
устройства, приложение или расчёт аналоговой модели.

Проверки и точная версия — в [progress](../progress.md) и отчёте независимого
критика. Временные PDF/PNG рендера находятся в build и не являются измерениями.
