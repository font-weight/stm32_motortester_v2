# V2-19 — дополнительные измерения видимого участка

Запрос 14.11.2026: к минимуму/максимуму/размаху добавить среднее напряжение
для DC, период и частоту повторяющегося сигнала; показывать причину отказа
при коротком, разорванном или нерегулярном участке. Плата ещё не получена.

Границы: один CH1, основное окно и открытые поддерживаемые записи.
Измеряется видимый временной интервал, не расстояние A–B. Исходные коды,
профиль файла и время не меняются. Среднее U=a*mean(code)+b только для
известного DC-входа; AC/неизвестная шкала объясняются. Служебные коды не В.
Период/частота — оценка повторения, не диагностика искры, цилиндра или горения.
Fs остаётся номинальной, если её физическая проверка не подтверждена.

Расчёт читает raw, не огибающую/прорежённые точки графика. Не более262144
отсчётов за запрос, один worker и один заменяемый запрос; при большем окне
попросить увеличить масштаб. В live только неизменяемая копия показанного
фрагмента. Не принимать старый результат после смены источника/интервала.
Отсутствующий или неполный raw не заменять поздним/нулевым/частичным.
Период требует минимум3 полных повторений, достаточную дискретизацию,
устойчивые интервалы и сходство формы циклов. Отказ имеет русскую причину.
Конкретные программные допуски документируются отдельно от аппаратной точности.

Не входят: PDF измерения, сравнение записей, RMS, новые окна, авто-диагноз,
прошивка, COM/SWD/CAD, физическая калибровка и реальные подключения.

Приёмка: необходимые модельные сценарии (DC/AC, sine/pulse, шум/нерегулярность,
short/gap/clip, знак gain, canonical10/12), Windows GUI с искусственным
источником, открытие/масштаб/смена источника без устаревших показаний,
перенесённый Windows-пакет, самостоятельный критик≥9,5 по quality-gate.
Предыдущая сборка v21w сохраняется. Фактические свидетельства — progress
и docs/reviews/v2-19-segment-measurements-review.md.
