# V2-18 — получение участка в мастере и отчёт

Запрос 14.11.2026: получать данные непосредственно в мастере калибровки,
затем добавить понятный отчёт; до получения аналоговой платы проверить
всё на искусственных данных. Рабочая основа — единое окно V2-17/v20w2.

## Ограниченный результат

- Мастер по отдельной команде получает новый ограниченный raw-фрагмент
  уже запущенного потока. Второго владельца COM, автоматического START,
  Stop или переключения физического входа не появляется.
- Показывает участок и позволяет принять только после ручного осмотра;
  измеренное U_CH1 вводит пользователь. Импорт сохранённых записей остаётся.
- На время ожидания фиксированы экземпляр, режим, формат/Fs, происхождение,
  владелец и сеанс. Обрыв, смена источника, неполный/старый участок, разрыв,
  таймаут отменяют запрос. Каждая точка начинается после своей команды.
- Учебный поток доступен явно внутри учебного сценария мастера; проходит
  тот же сбор новых блоков, никогда не становится калибровкой физического входа.
- Существующий mtcal v1 хранит исходные коды, индексы, происхождение, условия,
  две исходные точки и новый независимый контроль. Формулы не меняются.
- PDF-отчёт содержит результат, параметры, опорные и контрольную точки,
  a/b, ошибку и предел, исходное происхождение и ограничения. Доступен и
  для неудачного/незавершённого опыта. Не заменяет полный mtcal с raw.
- Переносимая Windows-сборка, понятная инструкция актуальных кнопок.

## Не входит

Физический COM, SWD, изменение прошивки/CAD, подача сигналов, подтверждение
точности, защиты, частотной характеристики или работоспособности платы.
Нет новых диагнозов, каналов, автоматического чтения мультиметра.

## Необходимые свидетельства

Адресные проверки свежести/отмены/смены режима и происхождения, несовместимого
или разорванного участка, PDF без перезаписи; учебные DC и AC с сохранением
и открытием mtcal. Native Windows GUI и frozen-пакет: новый сценарий без
serial-open, существующий offline-путь, просмотр PDF. Исходники/сборка и
результаты фиксируются manifest. Один независимый критик по quality-gate
с оценкой не ниже 9,5; реальный опыт остаётся следующим отдельным этапом.
