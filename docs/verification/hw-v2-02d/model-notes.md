# Расчётные границы P1-LV r2

Итерация HW-V2-02d. Это пояснение к
[модели](../../../hardware/v2-input/p1-lv/model.py) и
[численному результату](../../../hardware/v2-input/p1-lv/calculations.json).
Все значения ниже расчётные; физического макета и измерений они не подтверждают.
Фактически выполненные проверки и приёмка находятся в `docs/progress.md`
и отчёте независимого критика.

## Номиналы и область допуска

R1/R2 = 510 кОм, R3 = 240 кОм, R4 = 330 кОм, R5/R6 = 4,7 кОм,
R7/R8 = 2 кОм, R9 = 330 Ом — по одной детали в каждом месте, ±1%.
R10 = 33 кОм, R11 = 1 кОм, R12 = 10 кОм — ±5%, с предварительным
отбором по показанию мультиметра. RV1 остаётся 10 кОм ±20%; C — прежние.
Модель **сохраняет полный допуск ±5% R10…R12** и не сужает его по отбору.
ТКС, старение, шум и физические характеристики конкретных серий сюда не входят.

R12 — нагрузка питания, а не защитный шунт. При V_A = 3,2…3,4 В,
R12 = 9,5…10,5 кОм ток составляет 0,304762…0,357895 мА,
максимальная мощность — 1,216842 мВт. Эта арифметика объясняет нечувствительность
узла к точному номиналу, но не подтверждает запас регулятора конкретной платы.

## DC и местный источник

При V_A = 3,300 В номинальная передача:

`U_ADC = 0,1198910081744 × U_CH1 + 1,681471389646 В`.

В записи через питание коэффициент смещения `β = 0,5095367847411`.
Для идеального 12-битного ADC: `a = 0,006719970703125 В/код`,
`b = −14,025 В`. Это не назначенная реальному прибору калибровка.
Участок CH1 0…1 В занимает около 148,81 кодов номинальной шкалы.

На CH1 видны Rin = 1,158947368 МОм к открытому напряжению 1,910526316 В;
это не сопротивление к земле. Rth узла SUM = 122,288828 кОм.
При ±1% четырёх резисторов и фиксированных 3,300 В:

| Величина | Минимум | Максимум |
|---|---:|---:|
| k, В/В | 0,117796587252 | 0,122017517366 |
| ZERO, В | 1,664974245769 | 1,697962241534 |
| Rin, МОм | 1,147357895 | 1,170536842 |
| Открытый CH1, В | 1,894412230 | 1,926589595 |

TEST учитывает нагрузку работающего P1, а не только делитель RV1.
Номинальные CH1 для положений RV1 0 / 0,5 / 1:
0,001647080 / 0,390826218 / 0,775933988 В. ZERO задаёт отдельная
перемычка CH1–AGND; нижний край потенциометра через R11 не даёт точного нуля.

При R10/R11 ±5%, RV1 ±20%, делителе P1 ±1% и V_A = 3,2/3,4 В
верхнее положение даёт 0,608063495…0,949943410 В. Для этих положительных
сопротивлений максимум достигается у верхнего края RV1: с увеличением
положения растут и напряжение ненагруженного источника, и его сопротивление;
подпор P1 выше источника, поэтому нагрузка не создаёт большего внутреннего
максимума. Ошибки монтажа, обрыв земли/движка, чужой источник и запуск
реальной схемы в эту границу не входят.

Условный вольтметр 10 МОм в верхнем положении уменьшает CH1 на 0,667503 мВ.
Паспорт RM101/RM102 указывает 10 МОм для DC V; соответствие конкретному
прибору, диапазону и условиям пользователя ещё требуется установить.

## Фильтр и переходы

Собственные частоты секций: 3117,319169 / 3051,656729 Гц;
Q = 0,543139025 / 1,303840481. Полупередача по мощности соответствует
−3,0103 дБ относительно DC. Для двух секций без SUM и выходного RC она
находится около 3085,88 Гц. Полная идеальная цепь с номинальными
20 пФ SUM и 330 Ом/1 нФ даёт 3084,168662 Гц.

Для 1024 углов R5…R9 ±1%, сигнальных C ±2% частота полной цепи
лежит в 2993,167265…3178,814991 Гц. Здесь SUM Rth/C удерживаются
номинальными; это пределы **перебранных углов**, не полный бюджет точности.
Ни полоса реального TLV9064, ни нагрузка выборки ADC не моделируются.
Номинальные гипотетические 10/20/30 пФ SUM дают полюса
130,147 / 65,073 / 43,382 кГц.

Идеальные переходы используют номинальные компоненты и V_A = 3,300 В:

| Переход CH1, В | Минимум LP2, В | Максимум LP2, В |
|---|---:|---:|
| 0 → 1 | 1,681471390 | 1,815041430 |
| 1 → 0 | 1,667792358 | 1,801362398 |
| −1 → 1 | 1,561580381 | 1,828720462 |
| 1 → −1 | 1,534222317 | 1,801362398 |
| −10 → 10 | 0,482561308 | 3,153962114 |
| 10 → −10 | 0,208980666 | 2,880381471 |

Даже линейная модель даёт выброс относительно установившегося напряжения.
±10 В остаются исследовательским сценарием, а не разрешённым диапазоном.
Численное уточнение шага RK4 не оценивает физическую устойчивость ОУ;
перебор всех переходных углов и пусковых состояний не заявляется.

Для условного ёмкостного источника Cs = 1 пФ, Cg = 200 пФ модель
приращений с нагрузкой P1 даёт спад 99,981322% за 2 мс. DC-подпор в этом
сравнении исключён. P1 по-прежнему не подменяет вход пассивного датчика.

## Условный отбор трёх резисторов мультиметром

Используется правило из [RM101/RM102 User Manual](https://uelectronics.com/wp-content/uploads/2022/11/RM102-English.pdf):
на указанных диапазонах `±(0,5% показания + 3 единицы младшего разряда)`.
Оно применимо только если инструкция соответствует исправному экземпляру
и соблюдены её условия. Отбор не является поверкой мультиметра.

| Место | Номинал | Диапазон RM102 | Принимаемое показание | Условные границы с ошибкой прибора |
|---|---:|---:|---:|---:|
| R10 | 33 кОм | 60,00 кОм | 32,01…33,99 кОм | 31,81995…34,18995 кОм |
| R11 | 1 кОм | 6,000 кОм | 0,970…1,030 кОм | 0,96215…1,03815 кОм |
| R12 | 10 кОм | 60,00 кОм | 9,70…10,30 кОм | 9,6215…10,3815 кОм |

Окно показаний ±3% оставляет запас до полного допуска ±5% даже с указанной
ошибкой мультиметра. Для R10 на верхнем крае:
`33990 + 0,005 × 33990 + 3 × 10 = 34189,95 Ом`, то есть +3,606%.
Для R11/R12 худшая верхняя оценка +3,815%. Ошибка может иметь один знак
для многих измерений; усреднение нескольких показаний её не отменяет.

Измерять отдельный обесточенный остывший резистор, не касаясь пальцами
обоих металлических выводов; записать диапазон, показание и место R10/R11/R12.
Отбор не превращает деталь в заводскую 1%, не устанавливает её ТКС и не
разрешает заменить важные R1…R9 на 5%. При неизвестной инструкции/неустойчивом
показании эти окна нельзя считать метрологическим подтверждением.
