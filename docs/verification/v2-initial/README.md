# Свидетельства V2-01

20.10.2026. Фактический статус и версия — [progress](../../progress.md).
Эти файлы подтверждают программную проверку DEMO и окна Qt на Windows 10,
а не Windows EXE или физический прибор.

- `core-tests.txt` — восемь целевых проверок ядра, последний запуск после исправления
  фазы DEMO и независимого от holdoff периода осциллографа.
- `gui-result.json` — семь сценариев конечного кода, исходник результата
  `build/v2-gui-final/result.json`; `02_recording.png` — экран этой проверки.
- `visual-100.json`, `visual-150.json` — отдельные изображения и проверки раскладки,
  единиц и границ участка после последних исправлений.
- `01_scope.png`, `04_ignition.png`, `05_compact.png`, `06_single_ignition.png`,
  `07_rename.png`, `08_millivolts.png` — реальные изображения из
  `build/v2-visual-100-final2`. Диалог имени снят отдельно.
- `09_scope_150.png`, `10_compact_150.png` — избранные изображения из
  `build/v2-visual-150-final2`; в JSON исходные имена — `01_scope`, `05_compact`.
- `source-manifest.json` — SHA-256 байтов проверенных исходников в рабочем дереве.
  На checkout с преобразованием LF/CRLF байтовые хеши могут отличаться;
  неизменяемая Git-версия дополнительно указана в отчёте критика.

GUI smoke воспроизводится из корня с новой выходной папкой:

```powershell
.\.venv\Scripts\python.exe host\scripts\check_v2_gui.py build\v2-gui-new
```

Только изображения и адресная проверка раскладки/единиц:

```powershell
.\.venv\Scripts\python.exe host\scripts\capture_v2_ui.py build\v2-visual-new
$env:QT_SCALE_FACTOR='1.5'
.\.venv\Scripts\python.exe host\scripts\capture_v2_ui.py build\v2-visual-new-150
Remove-Item Env:QT_SCALE_FACTOR
```

Использовалась платформа Qt `windows`, не offscreen. Масштаб 150% — механизм Qt,
системный DPI Windows не менялся; перенос окна между мониторами не проверялся.
При 150% Windows ограничила исходное окно до 1283×707 логических единиц.
Минимальное поддерживаемое окно — 1024×700. Панель управления прокручивается.

В smoke диалоги выбора пути подменены фиксированными путями, реальные файловые
операции/worker/Qt callbacks выполняются. DEMO-таймер остановлен и продвигается
вручную; непрерывная работа Windows в течение часов не проверена.
Наблюдение 2 млн отсчётов — одна ограниченная проверка ресурса, а не бенчмарк.
Полный унаследованный набор не запускался. Повторы выполнялись после найденных
исправлений, а не для накопления количества PASS.
