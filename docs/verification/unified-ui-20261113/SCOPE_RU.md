# V2-17 — один основной экран

Запрос 13.11.2026: подключение, вход CH1, живой сигнал, запись, просмотр
файла и шесть крутилок на одном экране; мастер калибровки отдельный;
ДЕМО запускается только через «Сервис». Холодный запуск без COM/START/ДЕМО.

Уровень результата: программная логика на искусственном источнике,
нативный Qt GUI Windows 10 и переносимый Windows-пакет. Прошивка,
CAD, физическая калибровка, проверка аналогового входа и автомобиль вне задачи.

Сохраняются исходные данные, снимки профиля, качество и разрывы,
пауза просмотра отдельно от Stop, защита несохранённого захвата,
отдельные процедуры DC/AC. Расчётная шкала требует явного подтверждения
физического режима. Подключение проверяет возможности без запуска АЦП.
При просмотре файла новое подключение сохраняет файл до READY.

Приёмка: один основной график; COM и частота непосредственно на экране;
параметры входа и запуска в правой панели; переподключение и открытие
записи без закрытия рабочего экрана; видимые ошибки/качество при свёрнутых
сведениях; безопасное завершение; целевые тесты, GUI-снимки и проверка
переносимого пакета. Независимое ревью точного manifest ≥9,5/10.

Прежние рабочие сборки и пользовательские записи не изменяются.
