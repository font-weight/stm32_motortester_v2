# V2-23 — очистка воспроизводимых файлов проекта

Запрос пользователя 15.11.2026: удалить лишние файлы проекта.
Объём: локальные воспроизводимые Python-окружения старых сборок, кеши,
промежуточные результаты PyInstaller и полные дубли распакованных пакетов.
Архивные wheels удаляются только при совпадении каждого файла с сохраняемым
набором; распакованные пакеты — только после сверки полного состава и SHA256
с сохраняемым ZIP. Источники, ZIP/source.zip, журналы, manifest, снимки и
результаты, включая неудачные, сохраняются.

Защищены: `.git`, `.venv`, рабочий Git worktree `build/v18src`, текущая сборка
`build/v24w`, предыдущая `build/v23w`, зависимость сборщика `build/v18w2`,
компиляторы, резервные копии flash/RAM, raw/readback и аппаратная диагностика,
пользовательские записи, платы, оригиналы архивов и личные документы.
Факт игнорирования Git сам по себе не делает файл мусором.

Перед удалением фиксируется точный список абсолютных целей и их оснований.
Каждый путь проверяется внутри рабочей папки; reparse/symlink-переходы,
пересечение с tracked-файлами или worktree, активный процесс и изменение
состава запрещают удаление цели. Удаление — native PowerShell с LiteralPath,
без wildcard и передачи файловых команд в другую оболочку.

Проверки: независимый просмотр списка/скрипта до удаления; receipt фактически
удалённых каталогов/байт; сохранность защищённых файлов, рабочего Git и
действующих зависимостей; один запуск главного окна без подключения платы.
Обновить ignore-правила точечно. Не переделывать приложение/прошивку и не
запускать полный старый набор тестов. Финальная приёмка по quality-gate ≥9,5/10.
