# V2-16 — мастера калибровки и первое включение R53

Запрос 13.11.2026: мастер DC WIDE, подготовка отдельного AC-мастера,
проверка на искусственных данных и инструкция первого включения пользовательской
платы. Уровни результата: программная логика, Windows GUI/локальный пакет,
документация и расчёт. COM, SWD, перепрошивка и физическое измерение не входят.

Критерии до реализации:
- DC: два устойчивых исходных участка, независимый третий уровень, критерий
  ошибки фиксируется заранее, raw и условия сохраняются.
- AC: каждый режим отдельно; свой ноль, известная синусоида, её частота,
  определение амплитуды и подтверждение знака, независимая амплитуда контроля.
- Искусственный опыт не получает статус физической калибровки и не применяется
  к реальной плате. Калибровка не переносится между режимами, ADC/Fs, экземплярами.
- Применённые a/b едины для графика, курсоров, показателей и порога; прежние
  файлы читаются. Исходная запись неизменна, новый снимок сохраняется с новыми данными.
- Мастер доступен без платы; реальные данные импортируются из сохранённых записей
  с исходными кодами и контекстом. Нет ручной подмены происхождения.
- Инструкция соответствует пользовательскому CAD 110×55 мм и проверенной распиновке,
  отделяет предварительный осмотр, питание, проверку выхода и подключение PA0.
  Не подтверждает защиту/полосу/полный диапазон/зажигание.

Root: GUI, импорт raw, интеграция, адресная GUI-проверка, пакет, общие документы.
calibration_model: calibration.py, analog_profile.py, test_v2_calibration.py.
first_power_guide: инструкция MD/PDF, её генератор и first-power evidence.
calibration_critic: независимое заключение по точному manifest, без реализации.

Необходимые проверки: адресные тесты математической модели и недопустимых данных;
сценарий DC/AC-мастеров и сохранения/открытия в Windows (искусственные отсчёты);
тот же ограниченный сценарий собранного EXE; сверка pin/net инструкции и страниц PDF.
Полный исторический test-suite не запускается. Фактические результаты — progress
и отчёт независимого критика; отсутствие физических опытов остаётся явным.
