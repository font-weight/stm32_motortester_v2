# V2-20 — стабильные показатели и живая частота событий

Запрос14.11.2026: устранить чередование чисел с надписью чтения raw при
каждом живом кадре; показывать частоту пороговых событий независимо от
масштаба, в том числе при одном импульсе на экране.

Результат: основной экран Windows. Последние полностью рассчитанные
показатели остаются во время автоматического обновления и явно названы
последним рассчитанным кадром. Ручной выбор/новый источник очищают прежний
результат. Чтение raw остаётся фоновым и ограниченным.

Отдельная живая частота использует исходные индексы найденных событий и
номинальную Fs, последние2–8 интервалов. Недостаток событий, нерегулярность,
слияние контекстов, разрыв и отсутствие свежих данных имеют причину вместо
старого числа. Нет данных не означает0Гц. Пауза просмотра/масштаб/выбор
старого события не превращают эту оценку в измерение видимого участка.
Stop, файл, смена источника/параметров сбрасывают живое значение.

Приёмка: целевые модельные проверки и настоящий Windows GUI на искусственном
источнике; отсутствие мигания после первого результата; частота регулярных
импульсов, held/pause, устаревание, смена источника/Stop; геометрия без
перекрытия курсоров; проверка перенесённого Windows-пакета. Независимый
критик по quality-gate≥9,5 с точным manifest, без открытыхP0/P1.

COM/SWD, прошивка, CAD, аналоговая плата и пользовательские записи не
изменяются. Частота пороговых событий не подтверждает искру, цилиндр,
обороты или электрическую точность. Не менять waveform-period отказ из-за
ограничения только ради наличия отдельной частоты событий.
