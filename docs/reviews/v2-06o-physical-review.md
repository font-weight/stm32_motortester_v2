## Новый P1-O2-02: наблюдатель не связывается с SH

Обе64B копии равны64 нулевым байтам, SHA256 `f5a5fd42d16a20302798ef6ed309979b43003d2320d9f0e8ea9831a92759fb4b`. Декодер правильно вернул `INVALID`, `accepted_frozen_record=false`, `nominal_timing=null`; это не валидный снимок с нулём событий.

Причина доказана exact источниками и ARM-кодом: `mt_stream_progress.h:14` задаёт `MT_N_BUILD=0x56325347` (SG), а `paired()` сравнивает с фактическим `mt_stream_diagnostics.firmware_build=0x56325348` (SH). `bind()` возвращает отказ до заполнения bank. Header SHA256 `9bf52d95d4473d184686e1b650c40342e401950485c1f48d4ed4c581fc5de89d`, module C `eada6c8ee4996e96bf7e3749ce1ab7604d8d700fdedf356beed5f35293f10e77`; литерал SG сохранён в exact ARM `bind` по `0x0800A2D0`. Вызов `mt_progress_begin` есть в образе, но успешное связывание с SH невозможно.

`root_read_closed` выполнил8 чтений и успешно декодировал136B/регистры, затем завершился exit1 на недействительной64B. Исходный отказ сохранён; [отдельный supplement](../verification/v2-late-grant/physical-01/build/v6o-board-01/150000/hardware-procedure-facts.json) честно описывает это завершение. Повторных чтений, Reset, START или rollback не было.

## Явное пересмотренное заключение O1

Положительное утверждение [O1](v2-06o-review.md) о сохранении работоспособной64B диагностики **опровергнуто**. Исторические report/JSON и их9,625 не переписываются; это заключение имеет приоритет: **exact SH с полной заявленной областью O1 теперь REWORK из-за P1-O2-02**. Прежний PASS нельзя использовать как текущую приёмку полного кандидата.

Сборка, RAM/stack, порядок runtime в native-модели и byte-equivalence остаются фактически пройденными проверками. Однако они недостаточны для вывода о работе observer с новым build. Native O выключал observer, а decoder проверял synthetic SH legacy binding с прежним C-fixture. Непосредственное cross-build связывание actual observer не было проверено; критик также пропустил эту зависимость, ошибочно приняв byte-identical SG observer за совместимость с SH. Это дефект реализации и пробел прежнего ревью, не новая особенность аппаратуры.

Нельзя приписывать увеличение префикса с3072 у SG до20480 у SH только late grant: одновременно ненамеренно исчезла активная работа observer. Этот опыт не изолирует эффект переноса grant. Prepare/positive/zero-space/gap метрики64B для O2 **недоступны**, их нельзя восстановить из нулей или подставить из N2.
