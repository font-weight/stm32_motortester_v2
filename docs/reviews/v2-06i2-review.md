## 100k: обязательная диагностика отсутствует

Обе копии после100k **побайтно равны прежнему50k frozen136**. В них остаётся nonce `efa84ac39bfa0e52`; actual wire100k имеет `8a9bedb9515e7bf0`. Совпадение generation3 здесь недостаточно — request sequence нового сеанса начинается заново. Decoder правильно вернул `nonce_mismatch`, `accepted_frozen_record=false`. Старые flags0/poll1386/copy138 **нельзя приписывать100k**.

Независимые100k-регистры подтверждают stopped, PSC71/ARR9, ADC/DMA off и нужные clocks/reset. Их offline helper PASS проверяет отдельный аспект; равенство двух старых dumps не подтверждает их новую identity. Штатный100k wire и501670 сохранённых кодов — реальные положительные сведения, но не полный PASS предусмотренной приёмки. Это **не queue-full и не наблюдённый отказ100k передачи**.

Причина подтверждена exact source `build/v6i-fw-01/source/firmware/platform/mt_stream_diag.c`: freeze публикует phase3 (строка21), cycle вphase3 возвращает freeze_cycle (33), begin принимает лишьphase1 (65); пути3→1 между захватами нет. Legacy136 предназначен для одного attempted run после boot. В исходном допуске I2 **не выявлена несовместимость многосеансной процедуры с этим ограничением**. Факт сохранён, критерии задним числом не ослаблены. Существенный P1 процедуры: отсутствует обязательная диагностика, связанная со вторым сеансом. По quality-gate при отсутствии обязательного свидетельства оценка100k и общегоI2 — null.

Root правильно остановил последовательность перед150k. После отказа decoder он выполнил только offline проверку уже сохранённых100k-регистров; аппаратного повтора/смены частоты не было. Этот допуск больше не разрешает продолжить оставшийся150k. Для получения недостающих данных требуется **новый отдельно согласованный план**, учитывающий one-run-per-boot; не следует сбрасывать nonce-проверку, подменять старые dumps или запускать150k как продолжениеI2. Изменение прошивки не требуется для сохранения уже установленных положительных фактов.

Текущая SC загружается, связь и остановка подтверждены; оснований для обязательного возврата SB/S4 из этих данных нет. Пустой PA0 исключает выводы об аналоговом сигнале, точности ADC, калибровке и зажигании.
