## Условия допуска

1. Сохраняются подтверждённые условия: пустой PA0, питание от USB платы, ST-Link3,3В отключено, приложение закрыто, тот же единственный probe. Root — единственный владелец COM/SWD.
2. Разрешены запись точного BIN по `0x08000000`, verify и отдельное полное чтение37132 байт. Только после побайтного совпадения — reset/run. Затем реальное пользовательское переподключение USB и ответ о готовности; оно не заменяется ожиданием по таймеру.
3. До единственного START — exact build `0x56325341`, CAPS100000/1, один канал/12bit/DATA128. Probe явно проверяет build/Fs и отсутствие предыдущих данных; остальные поля отвергает существующий wire admission. Один Preview, затем целевой Record10с. Это не предельная общая длительность подключения: ожидания Preview/Record/cleanup ограничены отдельно, фактический интервал и overshoot сохраняются.
4. До любых SWD-чтений требуется закрытый владелец COM. В успешной ветви probe это `owners_closed=true`; в ошибочной — `cleanup_finished=true` **и** `final_state.phase=closed`. При отсутствии подтверждения сначала разрешить проблему владения; не продолжать к чтениям просто по истечении паузы.
5. После закрытия COM прочитать два legacy136 по `0x20002BC4` и указанные блоки регистров. Для физической приёмки обязательны одинаковые frozen записи правильной identity, flags0, poll/copy<5120мкс, TIM3 CEN0/PSC71/ARR9, ADC_CR2=0/SMPR2 low3bits4, DMA EN0 и действительные RCC clocks/resets.
6. Приёмка результата требует normal END reason0 и matching STOP ACK, правильных sequence/prefix/CRC, fresh Open/companion, полного сравнения выбранного raw с сохранённым wire. Темп90–110тыс./с по часам ПК — только грубая проверка. Неизвестный произведённый хвост остаётся неизвестным. Отказ сохраняется без второго START или скрытого повтора на другой Fs.
7. **Автоматического возврата S4 после ошибки нет.** По новому указанию пользователя кандидат можно оставить, только если подтверждены загрузка, связь и остановленный приём. Возврат допустим при конкретной записанной причине из плана: незавершённая запись/readback, неработающий boot/USB после запланированного replug, неподтверждённая остановка либо потребность пользователя в проверенной50k. Тогда вернуть всю свежую65536-копию, verify/независимый полный readback, reset/replug и исходный READY helper без START.
