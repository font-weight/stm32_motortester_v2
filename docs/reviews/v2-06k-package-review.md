# V2-06k — независимое ревью Windows-пакета DATA256

**PASS, 9,59/10**, 24.10.2026. Область: готовый локальный Windows-пакет,
перенос и изменённый сценарий выбора частоты/записи/открытия/экспорта с
синтетическим wire-источником. Критик `stream200_critic` не автор реализации
или упаковщика. Это отдельный результат от [software review](v2-06k-review.md).

не входят.

## Представленный запуск и личная проверка

Первый build и первый frozen run завершились успешно. Лог сохраняет точные
argv, времена и exit codes. Перенесённый EXE запущен с `--verify-profiles`
из другой рабочей папки с кириллицей, при `PATH=C:\Windows\System32`, без
Python/Qt overrides. Среда: Windows 10.0.19045 AMD64, Python 3.14.7,
PyInstaller 6.22.3, PySide6 Essentials 6.12.0; версии и hashes всех зависимостей
закреплены в manifest/lock. Frozen run длился 12,891 с и завершился с кодом 0.
Чистая Windows без установленной среды разработки не проверялась.

Критик прочитал конечный `profiles_package_check.py`, исходник smoke и
сохранённые receipts, лично просмотрел frozen live/Open/legacy mismatch PNG.
SC150 mismatch PNG совпадает по SHA с уже просмотренным source-снимком.
Надписи, шаг 6,66667 мкс, 10 старших бит и синтетическое происхождение читаемы;
сообщения несовместимости не обрезаны. Запуски не повторялись.

Девять проверок требуют явный mode4, discovery7, selected ACK/CAPS256,
блокировку выбора при захвате, отказ несовместимых legacy/SC150 до START,
запись, fresh Open, intrinsic quantization и CSV. Декодированная wire-сцена
содержит 1696 полных DATA256 и один terminal tail229, максимальный кадр 370
байт. Проверены последовательности, индексы и END CRC. После Open все
381 669 выбранных raw-кодов равны synthetic source; копия без companion
сохраняет ту же интерпретацию. Raw SHA:
`a31cc0904192fe4214cde3aefd96bab1e58cbdfafc4b493ac6743c475d6ed19b`.
Journal SHA:
`0cea106ffb902cb8ad0955c429afa059cf4174f3fce905e76b09fe1d55a0329c`.

CSV проверен по числу строк, столбцу retained10, identity, SHA и первым двум
временам с шагом 20/3 мкс; каждый код CSV отдельно не сравнивался. COM вызовов
0, владельцы закрыты, callback/errors пусты. Наблюдения 150096,5 samples/s,
34 мс service gap и backlog 5178/32768 относятся только к синтетическому
расписанию ПК. Они не являются измерением ADC/USB.

## Границы и итог

Запуск для пользователя: распаковать весь `MotortesterV2-windows-x64.zip`
и открыть `MotortesterV2.exe`; [README](../../README.md) содержит обычный
сценарий. Exact build расположен в `build/v6kw1`; источник и журнал
включены в приведённые hashes. Прежний большой suite и Inspect-сценарии
заново не запускались: проверена необходимая изменённая ветвь.
