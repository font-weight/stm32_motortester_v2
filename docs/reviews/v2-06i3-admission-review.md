Причина дельты установлена exact исходником: legacy136 замораживается после одного attempted run и не перевооружается HELLO/новой nonce. Явный MCU Reset/Run перед следующим опытом возвращает startup/BSS и начальную фазу observer; одна просьба переподключить USB не была бы достаточным доказательством reset при возможном питании через отладочные цепи. Новый план требует **оба** действия и их фактические свидетельства.

Условия допуска:

1. `program_limit=0`: тот же установленный SC,50k не повторять. Предыдущее100k уже имеет owners_closed и stopped-регистры. Плата/проводка/пустой PA0/закрытое приложение остаются прежними; только root обращается к аппаратуре.
2. Перед **каждым** из двух опытов root выполняет один закреплённый ST-Link `-Rst -Run`, сохраняет успешный результат и ожидаемый SN `57005400120000393333574E`. Затем пользователь реально переподключает USB платы и отвечает о готовности. Между reset и единственным START этого режима иных START нет. Ни задержка по времени, ни закрытиеCOM/HELLO не заменяют новый boot.
3. Порядок: **100k/12, Record5с**, затем только при полном успехе — новый Reset/Run и отдельный пользовательский replug, **150k/10, Record30с**. В каждом новый discovery0.2→fresh nonce0.3, exact SC/CAPS/mode до одного START. Не менять прежние сроки/критерии, не запускать следующий режим после любого отказа.
4. Сохранить raw/wire/CRC/fresh Open/companion, normal END reason0 и matching STOP_ACK, actual wall и грубый темп90–110% номинального. Для150k — retained10/drop2, canonical0…4092 кратный4 и время20/3мкс. Неизвестный произведённый хвост остаётся неизвестным.
5. SWD/halt запрещены во время приёма. После подтверждённого закрытия владельцев — свои две136 по0x20002BD4 с **новой actual nonce/generation**, flags0, poll/copy<5120 или3413мкс, stopped TIM3/ADC/DMA/RCC и PSC/ARR71/9 либо47/9. Старые I2-метрики не использовать. До следующего reset архивировать и проверить весь текущий результат. ADC_DR не читать. Audit16MiB и moduloDWT ограничения сохраняются.
6. При отказе остановить этот новый план, сохранить свидетельства. При подтверждённых boot/связи/остановке оставить SC; автоматического возврата SB/S4 нет. Условная аварийная процедура возврата полной SB из закреплённого плана допустима только при записанной конкретной необходимости запуска/связи/остановки, с verify/full readback и READY безSTART; это не обычный шагI3.
