## Условия исполнения

1. Только root: один Program/Verify, независимый полный readback с побайтным равенством, затем один Reset/Run. Любое несоответствие прекращает план; автоматического повтора или отката нет.
2. После Reset получить новый фактический ответ пользователя о USB replug. Runner связывает его с hash reset.log и ожидаемым COM6. До этого COM/START не открывать.
3. Только один START: mode5,150000 отсчётов/с,10 сохранённых бит, DATA1024, запрос3с Record после Preview. Discovery и выбранный сеанс имеют разные nonce; build/CAPS проверяются до START.50/100 и второй START не входят.
4. Пока COM-владелец активен, никаких SWD/Halt. Только после явного owner-close и offline-согласования END/STOP/ACK, nonce/generation/индексов/CRC разрешён reader. При таймауте или недостатке такого свидетельства чтение не разрешено этим путём.
5. Считать две копии136 байт по `0x20002F1C`, две64 по `0x20002FA4`, затем TIM3/ADC/DMA/RCC остановки. Диапазоны чтения исключают ADC_DR. Реальную хронологию, длительность и отсутствие Halt/Reset во время захвата root фиксирует отдельно.
6. Cap250мс — предел наблюдения по checkpoint, не остановка АЦП и не гарантия наблюдения более позднего отказа. DWT-время условно при интервале короче оборота32бит. FIFOacceptedbytes не равны wire prefix или USB-доставке. Раздельно сообщить исход захвата и пригодность диагностики.
7. На отказе сохранить данные и завершить этот план. SG оставить, если связь/остановка это позволяют; автоматических Reset/rollback/retry нет. Новое действие при иной необходимости потребует отдельного обоснования.
