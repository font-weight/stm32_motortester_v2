# HW-V2-02 — независимая проверка P1-LV

Дата: 20.10.2026. Репозиторий `font-weight/stm32_motortester_v2`,
ветка `ui-v2/initial-design`, база
`24cce1928e8a400010536bb38715e34948c17246`.
Проверяющий: отдельный агент `input_critic`; не автор схемы, модели,
нетлиста, методики или общих документов. Пишет только этот отчёт и собственные
свидетельства проверки.

**PASS, 9,68/10 — документация и воспроизводимая идеальная модель.**
Действует только для файлов/байтов из
[manifest](../verification/hw-v2-02/manifest.json).
Изменение содержательной части после manifest требует проверки разницы.
`sha256` фиксирует исходные байты рабочей копии; дополнительный
`sha256_lf_normalized` для UTF-8 текста допускает сверку нового checkout
после преобразования CRLF↔LF. Для PNG действует только хеш исходных байтов.
Оценка не является процентом надёжности, точностью измерения или разрешением
собирать/подключать зажигание.

## Область и требования

Применены пять критериев HW-V2-02 из `task.md`, V2-U01…U10 в относящейся
к документации части, правила `AGENTS.md` и действующая рубрика
[quality-gate](../quality-gate.md).
Проверены документация нового этапа, P1-LV netlist/BOM, SVG/PNG,
генераторы, расчётный JSON, идеальные графики и пустой журнал.
Исторические материалы P0 прочитаны для границ совместимости;
их прежняя приёмка или физическая пригодность заново не утверждаются.

P1-LV — оправданный ограниченный учебный макет без датчика: будущая
проверка DC-смещения, общего фильтра и передачи к ADC возможна от местного
источника. Его 1,140286 МОм и ненулевой подпор на CH1 сохраняются явно;
сокращение требований к пассивному датчику не скрыто. P0 с двумя шинами
и вариант активного пробника остаются отдельными направлениями.
Изготовление этого макета не объявлено обязательной закупкой для всего проекта.

## Лично проверенные свидетельства

Среда: Windows 10, build 19045; Python 3.14.7, 64 bit.
[Результаты арифметики](../verification/hw-v2-02/critic-check.json).

1. Один запуск `model.build()` через `.venv/Scripts/python.exe -B -`,
   с импортом по пути, без перезаписи авторского JSON. Полное дерево значений
   совпало с `calculations.json`, включая все трассы. Самопроверки модели
   дали остаток DC не более 6,284e-7 В, изменение совпадающих точек при
   уменьшении шага RK4 вдвое не более 1,887e-8 В.
2. Независимые от реализации передаточной функции узловые уравнения:
   для DC-сумматора максимальная невязка 3,389e-21 А; местного нагруженного
   источника 3,812e-21 А. Для каждой Sallen–Key секции решена комплексная
   система по X/Y; несовпадение модулей полной передачи с JSON не более
   4,441e-16. Это проверка уравнений/арифметики, не физических величин.
3. Просмотрены DC-углы: четыре резистора ±0,1%, шины 3,2/3,4 В;
   частотные углы: R5…R8 ±0,1%, C ±2%, R9 ±1%.
   Отдельные C1a/C1b в модели заменены общей 11,8 нФ с тем же пределом
   ±2%; одновременные крайние значения дают границы этой суммы.
   Частотные углы не охватывают все реальные паразитики, смещение ОУ
   или бюджет точности — ограничение правильно указано.
4. TEST от общей шины включает нагрузку P1, R11, допуск полного RV1
   и условный мультиметр. Нижнее положение даёт около 1,652 мВ,
   отдельная ZERO-перемычка нужна для нуля. Верхний рассмотренный угол
   0,922146927 В не распространяется на ошибку монтажа/обрыв земли.
   Номинальный пример Rвх=10 МОм не приписан RICHMETERS 102.
5. Визуально просмотрены `schematic.png` и `model-report.png`,
   прочитаны генераторы и SVG. Номиналы/сети, Cf на выход соответствующей
   секции, питание, замкнутые повторители, неопределённый монтаж RV1
   и снятая JP_ADC согласованы с netlist. Кириллица итоговых PNG читается.
6. По первичным [TI SBOS839N](https://www.ti.com/lit/ds/symlink/tlv9064.pdf)
   Fig. 5-13/table 5-5 проверены SOIC-14 и номера всех секций/питания.
   [ST DS5319](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)
   и [TI SLVAEX7A](https://www.ti.com/lit/an/slvaex7a/slvaex7a.pdf)
   подтверждают основания ограничений по опоре/аналоговому входу и
   подпитке через защитные структуры; конкретная плата ими не проверена.
7. Проверены локальные ссылки и CSV. До создания этого отчёта из 351
   проверенной ссылки единственной ожидаемо отсутствовавшей была ссылка
   на него. В CSV 16 колонок и 10 строк, все измерительные поля пусты.
   Окончательное разрешение ссылок и хеши фиксируются в manifest.

Программное приложение, COM, ST-Link и прошивка не запускались и не менялись
в этой проверке. Полный исторический набор тестов не выполнялся.

## Собранный список замечаний

**R1, P3, исправлено.** Первоначально `coordination.md` называл
`input_research` читателем без записи, хотя ему передали генератор схемы
и SVG/PNG. Перед окончательной фиксацией ownership исправлен.
Повторно прочитаны изменённые строки. Это исправление сопровождения,
не изменение электрических расчётов.

Открытых P0/P1 и отсутствующих обязательных свидетельств в заявленной
документационно-расчётной области не обнаружено. Дополнительных формальных
тестов ради повышения балла не потребовалось.

## Незакрытые последующие уровни

Не выполнены CAD/ERC, сборка, проверка настоящего TLV9064,
осциллографическая проверка пуска/выключения/устойчивости, испытание с ADC,
метрологическая калибровка и измерения датчика/зажигания/автомобиля.
Рабочий диапазон ±10 В и квалифицированная входная защита не назначены.
Схема питания конкретной платы, допустимый ток и характеристики
RICHMETERS 102 остаются TBD.

Последовательность следующего этапа сохранена: состав деталей/приборов
и CAD/монтаж → отдельный DC-контроль с JP_ADC снятой → обязательная проверка
переходов осциллографом → отдельный допуск ADC → реальные контрольные
точки/неопределённость и только затем профиль В/мВ. Программный интерфейс
назначения калибровки физическому потоку требует собственной итерации;
текущий UNKNOWN_PROFILE этим проектом не меняется.
