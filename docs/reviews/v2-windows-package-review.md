## Выполненная проверка

```powershell
.\.venv\Scripts\python.exe -u host\packaging\v2\build_windows.py --output build\v2w2
```

Критик лично прочитал исходники упаковки, актуальный diff, [журнал](../verification/v2-windows/build.log), [frozen receipt](../verification/v2-windows/frozen-smoke/result.json), [результат Inspect](../verification/v2-windows/inspect-report.json), manifest и метаданные CSV. Это не подмена исходников, но утверждение полного побайтного равенства архивных текстов и Git blobs было бы неверным.

Все неудачные результаты сохранены. Повторные сборки выполнялись после конкретных обнаруженных причин; первые две не дошли до frozen-сценария, третья завершилась на импорте Qt. В конечном состоянии выполнен один успешный ограниченный frozen workflow, отдельный CLI и штатный startup. Исторический набор и восемь тестов ядра V2-01 повторно не запускались.

Остаётся небольшая сложность сопровождения: V2-builder импортирует runner исторической упаковки и использует её большой collector уведомлений. Это осознанное переиспользование проверенных функций, но изменение старых модулей потребует проверки влияния на V2. Конкретного отказа конечного пакета из-за этой зависимости не обнаружено. Предупреждение PyInstaller об отсутствующем `OpenGL` относится к неиспользуемому `pyqtgraph.opengl`; поддержка 3D в V2-02 не заявлена.

## Границы и следующий шаг

Не выполнены: чистая Windows без установленного Python и инструментов разработки; проверка другой версии Windows; ручные файловые диалоги и длинный пользовательский сеанс; подпись/установщик; завершённый аудит соответствующих исходников всех зависимостей для публичного выпуска; реальный USB, низковольтное измерение, зажигание и автомобиль. Системный DPI в этой упаковочной итерации отдельно не менялся. Открытие legacy `.mtcap` не повторялось в frozen smoke; соответствующий код не менялся, и область утверждения о выполненном smoke ограничена `.mtv2`.

Пользователю: полностью распаковать проверенный ZIP или открыть уже проверенную папку `build/v2w2/Проверка переноса/MotortesterV2`, запустить `MotortesterV2.exe`, выполнить привычное DEMO → запись → остановить → сохранить → открыть. Для сообщения о проблеме сохранить SHA пакета, версию Windows и точное действие. Разработка реального источника остаётся отдельной V2-03.
