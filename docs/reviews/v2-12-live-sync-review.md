## Проверенный результат

Новый режим явно включается флажком. `aligned_event` выбирает последнее
доступное индексированное пересечение; два соседних исходных кода подтверждают
переход через настроенный порог с учётом полярности. Начальное активное
значение без предыдущего отсчёта не считается наблюдённым фронтом.
`baseline_unsettled` не запрещает настоящий плавный фронт.

Кадр шириной W задаётся развёрткой и начинается с `trigger−W//2`; весь диапазон
должен присутствовать в непрерывном raw-снимке. Границы не поджимаются к кольцу.
Для нечётной ширины допустимое смещение центра — половина отсчёта. Ось X
остаётся временем от левого края, маркер «Порог» показывает пересечение.
Исходные время и коды, EventConfig, детектор, запись и companion не меняются.

Один кадр завершается перед подготовкой следующего: новый live snapshot
не отменяет каждый уже готовый результат при очередном опросе. Обновление
метаданных продолжается; история кадров не накапливается. Ожидание нового
события/полного кадра обозначено, предыдущий кадр не выдаётся за свежий.
Мышь/X/A–B/навигация удерживают фрагмент, развёртка и Y сохраняют режим.
Пауза, Stop, файл, смена источника и закрытие снимают синхронизацию;
«К хвосту» снимает также паузу. Preview→Record сохраняет режим через
подготовку файла и ожидание границы записи.
