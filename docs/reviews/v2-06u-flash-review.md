## Условия исполнения root

1. Непосредственно перед Flash заново подтвердить ожидаемые COM6/PNP и ST-Link/SN, исправное состояние устройств и отсутствие app/capture owners. Сохранённый inventory 28.10 не заменяет эту проверку. PA0 пуст, прежняя низковольтная проводка и питание платы только USB сохраняются.
2. Ровно один program/verify SN; независимый readback всех **49744 байт** должен побайтно совпасть. Только затем один Reset/Run. При ошибке не продолжать автоматически.
3. После **этого SN Reset** получить новый фактический ответ пользователя: обе USB отключены 10 с, сначала USB платы, через 5 с ST-Link. Сохранить новый запрос/ответ, время и hash reset log. Старое «готово» для SL не подходит. Truthy reply в helper само по себе не доказывает хронологию; это обязанность root.
4. Перед единственным START — свежие COM6 / `USB\\VID_1209&PID_0001&MI_00\\6&D2DE68C&0&0000`, code0 и owners=[]; discovery0.2 → новый nonce HELLO0.3, точные SN/CAPS. Один mode5, 150000 Гц, DATA≤1024, retained10, запрос Record **30 с**. Других частот и повторов нет.
5. Пока COM owner активен, SWD/halt запрещены. Только сохранённое `owners_closed=true` либо `cleanup_finished=true` + phase closed **и** offline coherent END/STOP/ACK разрешают два чтения каждой банки: 136 `0x20002f1c`, 64 `0x20002fa4`, 24 `0x20002fe4`, затем stopped TIM3/ADC/DMA/RCC. ADC range `0x40012408` длиной 12 не включает `ADC_DR`. Root фиксирует действительную хронологию; helper-generated facts не являются независимым доказательством отсутствия SWD.
6. Любой отказ завершает этот план: сохранить оригиналы и SN, если подтверждены остановка/связь; без нового START, Reset, автоматического отката или 50/100 кГц. Без coherent terminal SWD-чтения этим допуском не разрешены.

Материальный критерий — полный 30-секундный поток 150 квыб/с без source fault/разрывов, с совпадающими raw/CRC/fresh Open/normal END/ACK и stopped registers. Успешный Flash, короткий сохранённый префикс или валидные диагностические bytes этого не заменяют. Gate24 — исторический переход до N CLOSING; его нельзя автоматически связать с более поздним USB snapshot64. CAP, unknown, invalidated, saturation и clock limits сохраняются; воздействия наблюдателя и полной WCET этот план не измеряет.
