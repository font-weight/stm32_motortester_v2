## Обязательные условия исполнения

1. Root непосредственно перед Flash проверяет свежие probe/COM6/PNP, исправное состояние устройств, отсутствие приложения/владельца захвата и сохранение пользовательских условий PA0 пустой, питание платы только USB. Старое inventory не заменяет эту проверку.
2. Один program с verify. Независимый полный readback должен побайтно совпасть с SI **до** единственного Reset/Run. При ошибке остановиться, не повторять автоматически Flash/Reset и не откатывать образ.
3. Только **новый фактический ответ пользователя о USB-replug после SI Reset**, связанный с hash этого reset log, разрешает последующий COM open. Старое «готово» не подходит. Перед open нужен свежий COM inventory.
4. Единственный START: discovery0.2 → freshnonce HELLO0.3 → точные SI/CAPS mode5/150000/10 сохранённых бит/max1024, затем запрос30с Record.50/100, повторный START и автоматический retry не входят.
5. Во время активного COM запрещены SWD/halt. Только явное закрытие владельца и offline согласованные END/STOP/ACK, nonce/generation, sequence/prefix/CRC/raw разрешают root_read_closed. Ветка PASS использует `owners_closed`; FAIL — `cleanup_finished` и phaseclosed. Timeout или отсутствие терминала не разрешают чтение платы.
6. После этих условий прочитать136 дважды с `0x20002F1C`,64 дважды с `0x20002FA4`, затем только stopped TIM3/ADC/DMA/RCC. Диапазон ADC `0x40012408..0x40012413` не содержит ADC_DR. Оба банка привязать к одному SI/image/nonce/generation; нулевой или несогласованный64 означает непригодную диагностику, а не отсутствие событий.
7. Успех диагностики не заменяет успех потока. Для30с требуются нормальный Stop, отсутствие sourcefault/gap, сохранённый raw/fresh Open, согласованный END/ACK и остановленные периферийные блоки. Ошибка helper/декодирования сохраняется вместе с уже полученными файлами, без автоматического повторения.

## Замечания и границы

Блокирующих замечаний в этом плане нет. Неблокирующие наследованные подписи helper: `IMAGE_SIA`/`SIA-256` и `expected_build_not_v2sh`; проверки значений, hashes и source строго используют SI. В каноническом physical report использовать правильные обозначения SHA-256/SI; immutable helper менять ради подписи до опыта не требуется.

P1-O2-02 исправлен программно; его фактический результат требует пригодного64B SI. O2 REWORK и INVALID zero64 остаются сохранёнными. **P1-M2-01 stable150k открыт**. SI возвращает observer overhead, отсутствовавшую в SH, поэтому рост префикса не изолирует эффект late grant. Приёмка относится к ограниченному опыту при данных условиях, не к аналоговому входу или автомобилю.
