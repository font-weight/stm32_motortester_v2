## Условия исполнения

1. Root — единственный аппаратный оператор. Непосредственно до Flash подтвердить ожидаемые COM6/PNP/probe и отсутствие владельца приложения/захвата. Пользовательские условия PA0 пустой, питание только USB платы сохраняются; старый inventory сам по себе не разрешает запись.
2. Один program/verify, независимый полный readback45372, затем один Reset/Run. При несовпадении прекратить план. Нужен **новый фактический USB-replug после SJ Reset**, записанный против этого reset.log; ранее данное «готово» не подменяет его.
3. Один START свежего сеанса: discovery→новый nonce→SJ mode5/CAPS150000/1024/retained10, запрос30с Record. Нет50/100, повторного START или автоматического отката.
4. Никаких SWD/halt при активном COM. Только после closedowner и offline согласованных END/STOP_ACK/nonce/gen/CRC — парные136 по `0x20002F1C`, парные64 по `0x20002FA4`, затем stopped TIM3/ADC/DMA/RCC. ADC_DR не читать. Валидность обеих диагностик требует точного SJ/image/session binding.
5. На отказе сохранить wire/raw/journal/companion/логи и остановить этот план. Установленная SJ остаётся, если состояние связи/остановки это допускает; автоматические Reset/retry/rollback не разрешены. Если closed/terminal gate не получен, reader не обходить — дальнейшее действие требует отдельного решения.

Root фиксирует реальный порядок операций и длительность, отсутствие SWD/halt. Записанные helper поля — процедурное заявление оператора, не независимый датчик этого факта. Timeout65с не доказывает интервал меньше DWT wrap≈59,65с при72МГц; модульные циклы, cap/overshoot, partial/unknown, saturation и invalid clock интерпретируются с фактическими внешними условиями. FIFOaccepted не равно полученным отсчётам; inclusive prepare не CPU share. Невалидный64B банк остаётся неприёмкой диагностики, даже при целостном wire prefix.
