# V2-05: опыт V2S3 после исправления границы CEN

План точного образа; загрузка только после независимого допуска.
Предыдущие опыты и возврат сохранены; их допуски не относятся к V2S3.
Условия платы и способ возврата из [первого плана](v2-stream-trial.md)
сохраняются. PA0 пустой; питание только USB платы, ST-Link без питания 3,3 В.

## Предмет допуска

- Опубликованная база `c10884fa39ad1a10ce0fcfc9d6e17f170e1e0bf0`.
- V2S3 build ID **0x56325333**; USB NVIC gate V2S2 сохраняется.
- Дополнительная цепочка `firmware/v2-stream/overlays/adc-cen.json`.
  Отдельный callback записывает TIM3 CEN между свежими чтениями TIM2 CNT.
  Полные проверки TIME и исходного USB actor/epoch/lifecycle окружают этот
  участок; метки согласуются с ними до публикации. Пределы 20 мкс и
  32 мс не увеличиваются; новый API не меняет layout прежнего guard.
- Окончательная сборка `build/v5-fw-09`, BIN **34400 байт / 0x8660**,
  SHA256 `a35d3675e5d9d3b8b6a60c2b7103b14d10f81d1f064a6884436a46d844977665`;
  ELF SHA256 `0fd03db44b669316fe44793e9776b7131d867063f9a446c777b0909f91de0108`.
  Static bound 3236/3240 байт при резерве 8192. Этот предел не WCET.
- Адреса данного ELF: diagnostics **0x2000238c**, 136 байт;
  main_last_runtime=0x20000478, usb_init=0x2000047c,
  irq_admitted=0x20000480, boot_failure=0x20000484;
  ADC start_before_us=0x200007c0, start_after_us=0x200007c4.
- Допуск: `docs/reviews/v2-05-transport-admission-03.md` для точных файлов.
  Это допуск 15-секундного опыта транспорта, не квалификация измерителя.

## Последовательность

1. Сверить единственный ST-Link `57005400120000393333574E`, SHA нового BIN
   и резервной копии первых 65536 байт:
   `72520303cd27bac89b9cd11d93ef751f0ec30617c1a90dc0427c7ba6a7665d39`.
   Закрыть владельцев COM; сохранить журналы в новом `build/v5-board-stream-03`.
2. После допуска — программирование по `0x08000000` с verify, отдельное
   чтение длины BIN и сравнение SHA. Не менять option bytes; без mass erase.
3. Reset/Run и переподключение USB платы пользователем. Уточнить COM;
   во время захвата не обращаться к плате через отладчик.
4. Один запуск `host/tools/v2_stream_probe.py`, 15 секунд записи, явные
   COM/build/source/image SHA, новый каталог `run`. HELLO/CAPS не запускают
   АЦП; после совпадения build — Start → Record → Stop → fresh Open → close.
   Повторного START при отказе нет.
5. Офлайн `host/tools/verify_stream_trial.py` сравнивает сохранённые
   raw с DATA из USB-обмена, проверяет CRC, последовательность и завершение.
   Сохранить `.mtstream`, companion, обмен и результаты без перезаписи.
6. После остановки — два чтения 136 байт диагностического record по адресу
   окончательного ELF. Проверить одинаковые bytes, magic/version/build,
   generation/nonce, phase=3, ADC STOPPED, hardware_off=1, adc_owned=0.
   Отдельно сохранить ADC start_before/start_after из RAM для проверки
   фактической номинальной скобки CEN. Это не независимая проверка частоты.
7. После успеха — отдельный reset перед записью с физическим отключением
   USB пользователем. Проверить сохранение префикса, неизвестный хвост и
   открытие; затем вернуть USB. Один record диагностики относится к одному boot.

При ошибке сохранить обмен/raw, выполнить Stop/закрытие владельца или
зафиксировать невозможность, затем читать RAM. Если остановка не подтверждена,
такое чтение — диагностика отказа с вмешательством, не свидетельство времени
нормального захвата.
Если нужен новый непроверенный код — вернуть старые 65536 байт, сверить
отдельным чтением, выполнить Reset/Run и USB-переподключение; проверить
прежний HELLO/CAPS без CONFIG/ARM/START.

Произведённый итог АЦП остаётся неизвестным и при штатном Stop. Равенство
доставленных байтов не означает отсутствие потерь до USB. Пустой вход не
проверяет В/мВ, полосу, точность времени, датчик или зажигание.
