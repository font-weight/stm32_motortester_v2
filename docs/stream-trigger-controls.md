# V2-11 — настройки программного поиска событий

Граница: управление существующим threshold-context-v1 на ПК; аппаратный
триггер и одиночный захват не входят. Перед live задаются порог и гистерезис
в шкале ADC12, направление, holdoff в мс, предел контекста в мс, предыстория
как доля этого предела и хвост после возврата. До известной шкалы никаких В/мВ.
В retained10 коды по-прежнему кратны4 в шкале0…4092, не0…1023.

Время переводится в целые отсчёты по согласованной Fs с округлением; actual
EventConfig отображается и сохраняется. Предыстория>=1; тихий базовый интервал
равен min(предыстория,0,5мс в отсчётах), минимум1. Предел контекста<=200мс,
pre+baseline+post+1<=max; неверная комбинация отвергается с объяснением.
Гистерезис — расстояние до уровня возврата: ниже порога для нарастающего
события, выше для спадающего. Конец события — тихий базовый интервал плюс
заданный хвост; это не фиксированное время от пересечения. Первое high тоже
может дать событие с baseline_unsettled/left_truncated, без обещания фронта.

Приём и запись фиксируют применённый config до Stop. Изменения доступны
до START; при активных владельцах/выборе файла/сохранении/ошибке закрытия
редактирование запрещено с объяснением. COM/ADC-команды не добавляются.
Preview→Record использует принятые controller.config/config_revision,
включая retry сохранения companion, а не ещё не применённые поля редактора.

Companion v4 хранит точный EventConfig, версию алгоритма и revision в новом
поле event_search; остальные binding/SHA256 проверки сохраняются. Читатель
понимает v1–3, где параметры не сохранены: fallback явно называется текущим
стандартным поиском. Неизвестная версия алгоритма не выдаётся за воспроизведение.
Raw MTSTREAM не меняется. Индекс file вычисляется заново от начала сохранённого
префикса, поэтому первые события могут отличаться от live.

В открытом файле Apply запускает отдельное переиндексирование через прежний
bounded worker/source token, сбрасывает выбор/курсоры, отбрасывает старые
результаты. Исходный companion и raw не переписываются; временные параметры
просмотра обозначены отдельно от исходного снимка и имеют местную revision.
Кнопка восстановления возвращает сохранённые параметры (либо явный default
для старого файла). Возврат к новому live не переносит file override молча.

Критерии: преобразование/границы50/100/150k и retained10; неизменные raw и
v4/legacy чтение; настоящий путь Windows GUI до старта, блокировка во время
записи, reopen/reindex и восстановление; frozen EXE и независимый критик>=9,5.
Только эти адресные проверки. Аппаратных измерений и перепрошивки нет.
