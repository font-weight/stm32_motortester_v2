# V2-05: опыт V2S4 с эквивалентным ускорением CRC

Область и условия [плана03](v2-stream-trial-03.md) сохраняются:
пустой PA0, питание USB, тот же единственный ST-Link без питания 3,3 В,
резервная оконная прошивка и проверенный способ возврата. Уточнение о
временно остановленном образе действует только во время активной работы.
Этот план не разрешает автоматически загрузить ещё не проверенный BIN.

## Точное состояние

- База `c10884fa39ad1a10ce0fcfc9d6e17f170e1e0bf0`, V2S4 build ID `0x56325334`.
- Новая цепочка `firmware/v2-stream/overlays/crc32.json`; одна неизменяемая
  таблица CRC32 во Flash для wire и накопленного raw-префикса.
- Формат, полином, отражение, начальное/финальное XOR и порядок байтов
  сохраняются. Размер очереди, кванты 64 байта, USB gate, частота 50 квыб/с,
  CEN и ограничения времени не меняются.
- Окончательная сборка `build/v5-fw-10`: BIN **35384 байта / 0x8a38**,
  SHA256 `04ba2853b6a964cd812bf555a32da7fb019bcd60ba9fda0bd586d71112b3143d`;
  ELF SHA256 `698895eb5a09fd801147db2a7d1dbbeded2e04d44388e1c880cb4c8d982b9de6`.
- Адреса RAM данного ELF прежние: diagnostics **0x2000238c / 136 байт**,
  main_last_runtime=0x20000478, usb_init=0x2000047c,
  irq_admitted=0x20000480, boot_failure=0x20000484,
  ADC start_before_us=0x200007c0, start_after_us=0x200007c4.
  Таблица CRC — 1024 байта Flash по 0x08008500; SRAM не увеличен.
- Независимый допуск — `docs/reviews/v2-05-transport-admission-04.md`.
  Он относится только к этому образу и короткому опыту.

## Порядок

1. Новый каталог `build/v5-board-stream-04`; проверить SN, SHA образа и
   резервной копии `72520303cd27bac89b9cd11d93ef751f0ec30617c1a90dc0427c7ba6a7665d39`.
2. После допуска загрузить BIN по 0x08000000, verify и отдельное чтение
   длины BIN; сравнить SHA. Reset/Run и USB-переподключение, уточнить COM.
3. Один `v2_stream_probe.py --seconds 15` с явными port/build/source/SHA.
   HELLO/CAPS → Start → Record → Stop → fresh Open → close.
4. Офлайн сравнить wire и raw, сохранить результат и оригиналы.
   После закрытия COM снять два 136-байтных record и RAM; проверить
   phase=3, hardware_off=1, adc_owned=0, ADC STOPPED, nonce/generation/build.
5. Рассмотреть очередь и интервалы обслуживания вместе с фактом 15-секундной
   передачи. Отсутствие заполнения за короткий опыт не обещает любой
   длительности или производительности на другом ПК.
6. После успеха отдельно перезапустить плату перед опытом физического
   USB-обрыва во время записи. Проверить доступный префикс и fresh Open,
   неизвестный хвост сохранить. Затем вернуть USB и готовое состояние.

При отказе нового START нет: сохранить данные, остановить/закрыть владельца,
после этого RAM. Если остановка не подтверждена, чтение — диагностика с
вмешательством, не timing evidence. При невозможности продолжить или
завершении работы без принятого преемника вернуть прежний образ по плану03.
Оригиналы неудачных опытов не заменять. Никаких выводов о В/мВ,
реальной точности Fs, пропущенных преобразованиях или зажигании.
