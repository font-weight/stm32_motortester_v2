# Унаследованные материалы исходного проекта

V2 импортирован с полной историей до `3ebfe1479056d64ce9c4a1eadad048f60ade100f` из [stm32_motortester](https://github.com/font-weight/stm32_motortester). Эти материалы сохраняют происхождение, авторство, инженерные основания, результаты и неудачные проверки исходного проекта. Импорт не превращает их в доказательства текущей версии V2.

Действующие точки входа: [README V2](../README.md), [требования V2](../requirements.md), [текущая задача](../task.md), [решения](decisions.md), [прогресс](progress.md), [приёмка V2](quality-gate.md). Старые блоки в requirements/task/decisions/coordination/quality-gate и host/README явно свёрнуты как исторические.

`DOT_START.md`, `DOT_PEER_START.md`, старые checkpoints/ревью, `mvp-spec.md`, `host/docs/*`, `firmware/`, `hardware/`, `protocol/` и их относительные ссылки продолжают описывать свои исходные версии. Старые firmware-gates не запрещают работу над интерфейсом V2. Напротив, при заявлении физических характеристик сохраняются реальные технические условия и запрет выдавать расчёт/синтетику за опыт.

Ссылки на Issues/PR/actions исходного репозитория оставлены как исторические первоисточники. Публикации новых изменений идут только в V2. Ни один старый статус software-ready/PASS, тестовый счётчик или Windows-лог не переносится на новую композицию автоматически. Историческая программа, формат и packaging могут запускать старый GUI; для V2 пользоваться новым entrypoint из README.

Прежний корневой README сохранён в свёрнутом историческом блоке исходного файла, чтобы его относительные ссылки продолжали работать.
