# V2-12 — синхронизация живого просмотра

После начала Preview доступен явный флажок «Синхронизация по событию · порог
в центре». Обычный live по умолчанию прокручивает хвост. Синхронизация берёт
новейшее индексированное событие, для которого весь кадр присутствует в raw.
Ширина W задаётся развёрткой, не фактической длиной события; start=trigger−W//2.
Для нечётного W центр отличается от геометрического не более чем на пол-отсчёта.
Предел live остаётся65536 отсчётов. Границы не поджимаются к кольцу: это вызвало
бы дрейф. Пересечение подтверждается двумя соседними raw-кодами перед trigger
и на trigger; начальное уже активное значение без предыдущей точки не подходит.
Baseline_unsettled возможен и на медленном действительном фронте, поэтому сам
этот флаг не отвергает кадр. Флаги контекста сохраняются:
такой кадр не обещает полного физического разряда.

Обновляется последняя доступная картина, не все события по очереди. Одна
подготовка кадра завершается перед следующей. Память ограничена прежними
snapshot/raw/worker; запись продолжает принимать все разрешённые исходные
отсчёты. Пропущенный экранный кадр не означает потерю записи. Исходные индексы
не меняются; ось X остаётся временем от левого края кадра, маркер показывает
порог в центре. Никакой интерполяции времени пересечения или калибровки нет.

При отсутствии нового подходящего события остаётся предыдущий кадр с явной
надписью об ожидании; до первого подходящего кадра график пуст. Изменение
развёртки выбирает новую ширину и может ждать её заполнения, не меняя Fs.
При смене ширины выбирается новейшее доступное окно под новый размер; в одном
размере номер автоматически выбранного события только возрастает.

Мышь (панорама/масштаб X), положение X, переход к событию и A–B отключают
синхронизацию и удерживают raw-фрагмент. Изменения Y её сохраняют. «К хвосту»
явно снимает удержание и паузу просмотра. Снятие самого флажка оставляет
последний кадр. Пауза/Stop/ошибка/закрытие/новый источник/файл снимают флажок;
повторное включение сбрасывает курсоры. Preview→Record сохраняет включённый
режим, включая подготовку файла. Настройки поиска и companion не меняются.

Критерий готовности: несколько новых trigger при одинаковом X/ширине,
новая развёртка, продолжение записи, ожидание без смещения, ручное удержание,
режимные переходы; один необходимый native и frozen сценарий, PNG, критик.
Физическая плата не требуется для этого программного шага. Одиночный захват
следующего события и его отдельное сохранение сюда не входят.
