МОТОРТЕСТЕР V2 — ПЕРЕНОСИМЫЙ ПАКЕТ ДЛЯ WINDOWS x64

Это технический кандидат для локальной проверки. Он работает с демонстрационными
сигналами, файлами, отдельными окнами STM32 по протоколу wire 0.1 и непрерывным
приёмом по wire 0.2/0.3 при наличии совместимой потоковой прошивки.
Пакет не подписан. Проверка на чистой Windows без Python ещё не подтверждена;
готовый публичный релиз не заявляется.

ВЫБОР 50 / 100 / 150 ТЫСЯЧ ОТСЧЁТОВ В СЕКУНДУ

Перед подключением выберите 50 тыс./12 бит, 100 тыс./12 бит или 150 тыс./10 бит.
Для переключения нужна прошивка wire 0.3. Старые wire 0.2 имеют фиксированную
скорость: программа проверит совпадение выбора с возможностями платы до запуска.
Для 150 тыс. нужна V2SE с пакетами по 1024 отсчёта (режим протокола mode5).
С прежними V2SC/V2SD этот выбор будет отклонён до запуска; их старые записи
продолжают открываться. Само наличие нового режима не подтверждает его
устойчивость на подключённой плате — результаты приведены в progress.
Старые записи 50/100/200 тысяч отсчётов/с продолжают открываться.
Обновление приложения само не перепрошивает плату. Фактически проверенные
скорости и установленная версия перечислены в docs/progress.md репозитория.

Физический АЦП всегда 12-битный. В режиме 150 тыс. передаются 10 старших бит;
два младших необратимо отбрасываются. Файл содержит эту отметку и без соседнего
контекста. Коды отображаются в прежнем 12-битном масштабе, с шагом 4 кода.
Время вычисляется по индексу и частоте: шаг 150 тыс. равен примерно 6,667 мкс,
без накопления округления. Режим нельзя менять во время приёма: остановите его,
закройте окно потока и подключитесь снова с новым выбором.

ПРОГРАММНЫЙ ПОТОК

Кнопка «Непрерывный приём · ДЕМО» открывает программный поток 50 000 отсчётов/с.
Включите служебные коды, запустите живой поток, начните запись с новым именем,
попробуйте паузу просмотра и нажмите «Остановить». Пауза не прерывает запись.
Откройте созданный .mtstream для просмотра и экспорта CSV + JSON.
Храните .mtstream вместе с соседним .v2.json: это контекст и хеш записи.
Профиль выбирается в главном окне до создания окна потока.
Неизвестный вход показывает только коды, без выдуманного напряжения.

ЗАПУСК ПАКЕТА

1. Полностью распакуйте MotortesterV2-windows-x64.zip в удобную папку.
2. Откройте папку MotortesterV2 и запустите MotortesterV2.exe.
3. Python отдельно устанавливать не требуется: необходимые компоненты включены
   в пакет. Сохраняйте папку _internal рядом с EXE. Не запускайте программу
   прямо из ZIP и не переносите один EXE отдельно от остальных файлов.

Для переноса на другой путь копируйте всю папку MotortesterV2, включая _internal,
licenses и остальные материалы. MotortesterV2Inspect.exe — дополнительная
консольная программа для чтения и экспорта записи; обычный запуск — через
MotortesterV2.exe.

ПЕРВЫЙ СЦЕНАРИЙ — ДЕМО

1. Для обычного сигнала выберите профиль «Осциллограф» и источник
   «ДЕМО · синусоида» либо «ДЕМО · прямоугольный».
2. Для импульсов выберите профиль «Зажигание» и отдельно
   «ДЕМО · зажигание». Профиль меняет инструменты, но сам не подменяет сигнал
   или калибровку. Все эти сигналы синтетические.
3. Попробуйте масштаб, курсоры A–B и паузу просмотра.
4. Нажмите «Начать запись», затем «Остановить запись». Пауза просмотра
   не останавливает запись.
5. Сохраните результат в .mtv2 через кнопку сохранения и откройте его повторно.
   Имя файла и папку выбираете вы. Экспорт данных создаёт .csv и соседний
   .csv.json; храните их вместе. Основным форматом остаётся .mtv2.

Доступны одиночный программный захват с предысторией и повторный захват.
В профиле зажигания запись позволяет переходить между кандидатами событий.
Это не автоматический диагноз, номер события не означает номер цилиндра.

STM32 — НЕПРЕРЫВНЫЙ ПРИЁМ, WIRE 0.2 / 0.3

Это отдельный режим для совместимой потоковой прошивки. Оконная прошивка wire 0.1
с ним несовместима: программа откажет в запуске после проверки версии.
Приложение не перепрошивает плату и не подтверждает состав образа по одному
объявленному номеру сборки. Диагностическая прошивка и её допустимое применение
проверяются отдельно; наличие этого режима не означает приёмку прибора.

1. Нажмите «Непрерывный приём · STM32», вручную выберите порт своей платы
   и откройте панель. При открытии панели порт ещё не подключается.
   Перед этим освободите порт в оконном режиме; одновременно использовать его
   в двух режимах нельзя.
2. Выберите скорость и нажмите «Подключить COM…». Выполняется только проверка версии и возможностей
   (HELLO/CAPS), без команды запуска АЦП. Дождитесь «Подключено · готово к запуску».
   Если устройство несовместимо или подключение не удалось, следуйте сообщению;
   автоматической замены прошивки или скрытого перезапуска нет.
3. Включите «Показать служебные коды АЦП» и нажмите «Живой поток».
   Физическая шкала пока неизвестна: показываются исходные коды, без В/мВ.
   Время рассчитывается по объявленной номинальной частоте; это не измерение
   точности тактового генератора.
4. Во время живого просмотра нажмите «Начать запись…», выберите папку и новое
   имя .mtstream. Приём продолжается во время выбора имени. Запись начинается
   после подтверждения; ранее показанные отсчёты автоматически в неё не входят.
   Существующий файл не перезаписывается. Пауза просмотра не останавливает запись.
5. Нажмите «Остановить» и дождитесь завершения записи. Откройте её кнопкой
   «Открыть запись…». Храните .mtstream вместе с соседним .mtstream.v2.json:
   там сохранены имя CH1, неизвестный профиль входа, сведения подключения и хеш.
   Без контекста файла DEMO-калибровка к нему не применяется.
6. Для завершения отключите и закройте панель. Порт закреплён за ней до окончания
   закрытия. При ошибке закрытия используйте «Повторить закрытие порта»;
   скрытие окна не подтверждает освобождение порта. Для новой попытки после
   остановки или ошибки закройте панель и откройте её снова.

У диагностической прошивки конец потока может оставаться неизвестным даже после
ответа на Stop. Надпись о неизвестном хвосте означает, что сохранён проверенный
префикс, но не доказана доставка всех последних отсчётов. Это не ноль потерь:
число отсутствующих отсчётов нельзя достоверно восстановить. Разрывы и признаки
неполноты сохраняются; приём не склеивает отдельные оконные захваты.

STM32 — ПОДКЛЮЧЕНИЕ И ОДНО ОКНО, WIRE 0.1

Для первой проверки используйте существующее подключение платы, не подключая
новый внешний сигнал. Перепрошивка для этого сценария не выполняется.

1. Выберите источник «STM32 · COM-порт» и откройте «STM32 · подключение».
   Выберите COM-порт своей платы вручную; номер может отличаться на другом ПК.
   Нажмите «Подключить»: это только проверка версии и возможностей, без запуска
   АЦП. Дождитесь готовности соединения. Объявленная устройством версия сама
   по себе не подтверждает модель микроконтроллера или состав прошитого образа.
2. Шкала физического входа пока не настроена. Для служебного просмотра отдельно
   включите «Показать служебные коды АЦП». Кривая показывает исходные коды,
   а не напряжение на разъёме; В/мВ для неизвестного входа не подставляются.
3. Нажмите «Получать окна · Auto». Получаются независимые окна по 2048 отсчёта.
   Без подходящего фронта Auto может завершить окно по таймауту с отметкой.
   Дождитесь нужного окна и нажмите «Остановить получение» (Stop).
4. Для одиночного окна выберите «Один захват · ждать фронта» (Single).
   Он ждёт пересечения служебного порога кодом АЦП; если фронта нет, ожидание
   продолжается. Отменить ожидание можно кнопкой остановки.
5. После завершения или остановки нажмите «Сохранить окно»: сохраняется последнее
   полное окно в .mtv2. Его можно открыть повторно и экспортировать в .csv
   с .csv.json. Неизвестная шкала останется неизвестной и в файле.
   Неполное окно можно сохранить через «Сохранить неполные данные · JSON».
6. Нажмите «Отключить» и выберите ДЕМО-источник для возврата к примерам.
   Если приложение требует физического сброса, отмечайте соответствующий
   флажок только после фактического сброса или переподключения платы.

Промежутки между окнами неизвестны: Auto не является непрерывной записью.
Этот оконный режим не выполняет непрерывную запись, окна не склеиваются.
Отдельный режим непрерывного приёма требует совместимой прошивки wire 0.2.
Порог задаётся в кодах 1…4094; предыстория — 0, 25 или 50% при поддержке платой.
Фронт относится к коду АЦП, а не к подтверждённой полярности напряжения.
Аппаратной паузы запуска (holdoff) нет. Масштаб графика не меняет частоту АЦП.
Пауза просмотра не заменяет Stop; при ошибке остановки следуйте сообщению
в панели, не считайте скрытие панели подтверждением остановки.

ЗАКРЫТИЕ С НЕЗАВЕРШЁННЫМ ОКНОМ

Если остались несохранённые фрагменты, при закрытии предлагается выбор:

- «Сохранить JSON» — выбрать файл и сохранить неполные данные, затем продолжить
  закрытие. Отмена выбора файла или ошибка записи оставляет программу открытой
  и сохраняет фрагменты в памяти.
- «Закрыть без JSON» — отказаться от сохранения показанного неполного окна.
  Только эти несохранённые фрагменты будут потеряны.
- «Отмена» — остаться в программе, сохранив фрагменты в памяти. Это вариант
  по умолчанию; закрытие самого диалога также отменяет выход.

Сохранённая ранее запись .mtv2 не меняется при любом выборе. Если появилось
другое неполное окно, для него потребуется отдельное решение. Отказ от JSON
не отменяет проверку остановки устройства: при ошибке следуйте сообщению.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ

Один CH1, два профиля, напряжение на разъёме в В/мВ. Пересчёта в киловольты
зажигания нет. DEMO имеет собственный синтетический профиль пересчёта;
он не назначается неизвестной плате.

Запись .mtv2 в главном окне ограничена 2 000 000 отсчётов — 40 секунд данных DEMO
при 50 кГц. Это не ограничение отдельной потоковой записи .mtstream.
Достижение предела завершает запись с сообщением, начало не перезаписывается.
Недавний сигнал содержит одну секунду отсчётов; пропуски сохраняются.
Одиночное окно осциллографа — до 1 секунды, контекст одной искры — 5 мс.
Эти числа описывают программную демонстрацию, а не характеристики прибора.

При записи и просмотре сохранённого захвата параметры получения данных
заблокированы. Масштаб, положение изображения и курсоры доступны для просмотра.
Старые .mtcap открываются без придуманной шкалы напряжения. .mtrec этот новый
пакет не открывает; для него сохраняется прежнее приложение из исходников.

Состояние физического входа — «Шкала напряжения не настроена». Показ вольтов
на DEMO или получение аппаратного окна не подтверждает допустимое подключение,
точность или полосу входа. Настройка и калибровка входа — отдельный этап.

НАСТРОЙКИ И ВАШИ ФАЙЛЫ

Пользовательское имя CH1 сохраняется отдельно от папки программы в настройках
текущей учётной записи Windows через Qt QSettings (MotortesterV2/Desktop).
Перенос папки программы сам по себе не переносит эти настройки другому
пользователю. Открытая запись использует сохранённое в ней имя и профиль.

Программа сохраняет записи и экспорт в выбранные вами папки. Для .mtv2 данные
в памяти автоматически не становятся файлом: сохраняйте нужное перед закрытием.
Потоковая .mtstream записывается в выбранный файл во время приёма и завершается
после остановки. Если контекст .v2.json не удалось сохранить, программа предложит
повторить сохранение или явно закрыться без контекста; уже записанные raw остаются.

ЧТЕНИЕ БЕЗ ОКНА — НЕОБЯЗАТЕЛЬНО

Откройте PowerShell в папке MotortesterV2. Укажите существующий файл записи,
при необходимости с полным путём:

.\MotortesterV2Inspect.exe "запись.mtv2"
.\MotortesterV2Inspect.exe "запись.mtv2" --csv "анализ.csv"
.\MotortesterV2Inspect.exe "запись.mtv2" --start-index 10000 --stop-index 20000 --csv "участок.csv"

Границы — индексы исходных отсчётов, правая граница не включается.
Команда выводит сведения в JSON и не перезаписывает существующий экспорт.

СОСТАВ И ПРОИСХОЖДЕНИЕ

build-manifest.json описывает исходную версию и сборку. LICENSE, licenses/
и LICENSE-REVIEW.md сохраняют лицензии, уведомления и открытые вопросы аудита
сторонних компонентов. Сборка этого кандидата не означает, что все вопросы
соответствующих исходников библиотек и условий публичного выпуска закрыты.

Комплект сборки включает рядом с ZIP программы source.zip, SHA256SUMS.txt
и журналы сборки. source.zip содержит материалы приложения и не заменяет
полный соответствующий исходный код всех сторонних библиотек.

Проект: https://github.com/font-weight/stm32_motortester_v2
Фактические проверки и ограничения конкретной версии: docs/progress.md
в репозитории. Для сообщения о проблеме укажите исходную версию из manifest,
версию Windows, масштаб экрана и действие, после которого возникла проблема.
