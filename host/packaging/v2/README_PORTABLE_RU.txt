МОТОРТЕСТЕР V2 — ЕДИНОЕ ГЛАВНОЕ ОКНО

1. Запустите MotortesterV2.exe.
2. Выберите COM-порт и частоту в верхней строке, нажмите «Подключить».
   Это проверяет соединение; АЦП ещё не запускается.
3. Если аналогового тракта пока нет, оставьте справа
   «Прямой PA0 / неизвестный вход». Показаны только коды АЦП.
4. Для платы R5 выберите DC + WIDE, AC + WIDE или AC + SENSITIVE.
   В «Настройка входа» укажите имя экземпляра, подтвердите фактические
   переключатели S1/S2 и нажмите «Применить вход».
5. Нажмите «Живой поток». Для записи — «Начать запись…» и новое имя файла.
6. «Остановить» завершает приём; «Пауза просмотра» останавливает только показ.
7. «Открыть запись…» открывает .mtstream, .mtshot, .mtv2 и .mtcap в том же окне.
   Для возвращения к прибору снова нажмите «Подключить», затем «Живой поток».

График, параметры входа, крутилки, захват и запись находятся на одном экране.
На небольшом экране нижние дополнительные параметры доступны прокруткой
правой панели. «Технические сведения» раскрывают подробности; ошибки
и качество данных показываются независимо от этого флажка.

V2-21: «Затухающие колебания» внизу основного окна удерживает видимый
участок для анализа, приём и запись продолжаются. «Предложить участок»
выделяет кандидата; осмотрите его и нажмите «Рассчитать». Можно двигать
границы мышью. Частота, τ и исходные пики описывают записанный отклик,
а не состояние катушки. При плохих данных показывается причина отказа.
Без платы: «Сервис → ДЕМО для проверки → Затухающие колебания · учебная запись».
Учебный ориентир: около 2500 Гц, τ около 1,2 мс.
Подробности — «Затухающие колебания_RU.md» рядом с EXE.

V2-20: показатели живого кадра обновляются без мигания сообщения чтения.
«Частота событий (живой приём)» — отдельная оценка по истории пороговых
событий, независимо от масштаба и паузы просмотра. Не является RPM или
подтверждением искры. При недостатке данных — причина вместо числа.
См. «Частота событий_RU.md».

V2-19: под графиком измеряется видимый участок по исходным отсчётам:
минимум, максимум, размах, среднее DC на CH1 и период/частота повторений.
Выберите участок крутилками «Развёртка» и «Положение X». Если данных
недостаточно, есть разрыв или сигнал нерегулярен, вместо периода видна
причина. Для AC постоянная составляющая не измеряется. A–B остаются
измерением двух точек, а не границами этого автоматического расчёта.

Калибровка — отдельный мастер «Калибровка…» справа. Его можно проходить
на учебных данных без платы, но такой результат нельзя назначить прибору.
V2-18: в «Источник данных» выберите «Учебный поток · без платы».
Для каждой точки нажмите «Получить учебный участок», осмотрите график,
подтвердите установление и нажмите «Использовать участок».
Для реального источника сначала запустите «Живой поток» в главном окне,
затем в мастере выберите «Живой поток STM32». Мастер не управляет COM/АЦП.
«Сохранить отчёт PDF…» сохраняет читаемый отчёт; полный результат с raw
сохраните отдельно через «Сохранить результат и исходные отсчёты…».
ДЕМО доступно только через «Сервис → ДЕМО для проверки → Осциллограф»
или «Зажигание». При запуске приложения искусственный сигнал не включается.

Подробные инструкции рядом с EXE:
- Главный экран_RU.md — кнопки, управление графиком и сохранение;
- Калибровка_RU.md — отдельные процедуры DC и AC;
- Измерения участка_RU.md — среднее, период и причины недоступности;
- Первое включение платы_R53.pdf — электрическая методика.
В PDF сохранены прежние названия окон; для программы используйте MD-инструкции.
Электрическая схема и методика включения в этом обновлении не менялись.

ФОРМАТ И ДАННЫЕ

Один канал CH1. Шкала В/мВ относится к входному разъёму перед делителем.
Неизвестный вход — только коды АЦП; расчётная шкала не является калибровкой.
AC не измеряет постоянную составляющую. Профиль «Осциллограф»/«Зажигание»
не переключает S1/S2. DC + SENSITIVE не является разрешённым рабочим режимом.

50/100 тыс. отсчётов/с сохраняют 12 бит. Для 150 тыс. передаются 10 старших
бит, а файлы содержат нормализованные коды ADC12 с шагом 4. Требуется
совместимая прошивка wire0.3 с пакетным режимом mode5; старые несовместимые
возможности отклоняются до запуска. Программа сама не перепрошивает плату.
Фактическая устойчивость и версия прошивки перечислены в docs/progress.md
репозитория; эта сборка проверена на искусственном источнике.

Храните .mtstream вместе с соседним .mtstream.v2.json. .mtshot — отдельный
захваченный контекст, а не вся непрерывная запись. Файлы .mtv2/.mtcap читаются
в исходной модели с их пропусками и временной основой, без придумывания
потоковых событий. Просмотр и экспорт не меняют исходные записи.

Это локальный технический кандидат Windows x64, не публичный релиз.
Пакет не подписан. Проверка чистой Windows без Python не заявляется:
проверяется перенос папки и запуск EXE на имеющейся Windows 10.
Программные проверки не подтверждают защиту, диапазон, изоляцию,
полосу аналогового тракта или готовность подключаться к автомобилю.
Лицензии зависимостей и LICENSE-REVIEW.md находятся рядом с EXE.
