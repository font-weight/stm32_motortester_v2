МОТОРТЕСТЕР V2 — ПЕРЕНОСИМЫЙ ПАКЕТ ДЛЯ WINDOWS x64

Это технический кандидат для локальной проверки. Он работает с демонстрационными
сигналами, файлами и отдельными окнами STM32 по протоколу wire 0.1.
Пакет не подписан. Проверка на чистой Windows без Python ещё не подтверждена;
готовый публичный релиз не заявляется.

ЗАПУСК

1. Полностью распакуйте MotortesterV2-windows-x64.zip в удобную папку.
2. Откройте папку MotortesterV2 и запустите MotortesterV2.exe.
3. Python отдельно устанавливать не требуется: необходимые компоненты включены
   в пакет. Сохраняйте папку _internal рядом с EXE. Не запускайте программу
   прямо из ZIP и не переносите один EXE отдельно от остальных файлов.

Для переноса на другой путь копируйте всю папку MotortesterV2, включая _internal,
licenses и остальные материалы. MotortesterV2Inspect.exe — дополнительная
консольная программа для чтения и экспорта записи; обычный запуск — через
MotortesterV2.exe.

ПЕРВЫЙ СЦЕНАРИЙ — ДЕМО

1. Для обычного сигнала выберите профиль «Осциллограф» и источник
   «ДЕМО · синусоида» либо «ДЕМО · прямоугольный».
2. Для импульсов выберите профиль «Зажигание» и отдельно
   «ДЕМО · зажигание». Профиль меняет инструменты, но сам не подменяет сигнал
   или калибровку. Все эти сигналы синтетические.
3. Попробуйте масштаб, курсоры A–B и паузу просмотра.
4. Нажмите «Начать запись», затем «Остановить запись». Пауза просмотра
   не останавливает запись.
5. Сохраните результат в .mtv2 через кнопку сохранения и откройте его повторно.
   Имя файла и папку выбираете вы. Экспорт данных создаёт .csv и соседний
   .csv.json; храните их вместе. Основным форматом остаётся .mtv2.

Доступны одиночный программный захват с предысторией и повторный захват.
В профиле зажигания запись позволяет переходить между кандидатами событий.
Это не автоматический диагноз, номер события не означает номер цилиндра.

STM32 — ПОДКЛЮЧЕНИЕ И ОДНО ОКНО

Для первой проверки используйте существующее подключение платы, не подключая
новый внешний сигнал. Перепрошивка для этого сценария не выполняется.

1. Выберите источник «STM32 · COM-порт» и откройте «STM32 · подключение».
   Выберите COM-порт своей платы вручную; номер может отличаться на другом ПК.
   Нажмите «Подключить»: это только проверка версии и возможностей, без запуска
   АЦП. Дождитесь готовности соединения. Объявленная устройством версия сама
   по себе не подтверждает модель микроконтроллера или состав прошитого образа.
2. Шкала физического входа пока не настроена. Для служебного просмотра отдельно
   включите «Показать служебные коды АЦП». Кривая показывает исходные коды,
   а не напряжение на разъёме; В/мВ для неизвестного входа не подставляются.
3. Нажмите «Получать окна · Auto». Получаются независимые окна по 2048 отсчёта.
   Без подходящего фронта Auto может завершить окно по таймауту с отметкой.
   Дождитесь нужного окна и нажмите «Остановить получение» (Stop).
4. Для одиночного окна выберите «Один захват · ждать фронта» (Single).
   Он ждёт пересечения служебного порога кодом АЦП; если фронта нет, ожидание
   продолжается. Отменить ожидание можно кнопкой остановки.
5. После завершения или остановки нажмите «Сохранить окно»: сохраняется последнее
   полное окно в .mtv2. Его можно открыть повторно и экспортировать в .csv
   с .csv.json. Неизвестная шкала останется неизвестной и в файле.
   Неполное окно сохраняйте отдельно через «Сохранить неполные данные · JSON».
6. Нажмите «Отключить» и выберите ДЕМО-источник для возврата к примерам.
   Если приложение требует физического сброса, отмечайте соответствующий
   флажок только после фактического сброса или переподключения платы.

Промежутки между окнами неизвестны: Auto не является непрерывной записью.
Непрерывная запись для STM32 в этой версии недоступна, окна не склеиваются.
Порог задаётся в кодах 1…4094; предыстория — 0, 25 или 50% при поддержке платой.
Фронт относится к коду АЦП, а не к подтверждённой полярности напряжения.
Аппаратной паузы запуска (holdoff) нет. Масштаб графика не меняет частоту АЦП.
Пауза просмотра не заменяет Stop; при ошибке остановки следуйте сообщению
в панели, не считайте скрытие панели подтверждением остановки.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ

Один CH1, два профиля, напряжение на разъёме в В/мВ. Пересчёта в киловольты
зажигания нет. DEMO имеет собственный синтетический профиль пересчёта;
он не назначается неизвестной плате.

Запись ограничена 2 000 000 отсчётов — 40 секунд данных DEMO при 50 кГц.
Достижение предела завершает запись с сообщением, начало не перезаписывается.
Недавний сигнал содержит одну секунду отсчётов; пропуски сохраняются.
Одиночное окно осциллографа — до 1 секунды, контекст одной искры — 5 мс.
Эти числа описывают программную демонстрацию, а не характеристики прибора.

При записи и просмотре сохранённого захвата параметры получения данных
заблокированы. Масштаб, положение изображения и курсоры доступны для просмотра.
Старые .mtcap открываются без придуманной шкалы напряжения. .mtrec этот новый
пакет не открывает; для него сохраняется прежнее приложение из исходников.

Состояние физического входа — «Шкала напряжения не настроена». Показ вольтов
на DEMO или получение аппаратного окна не подтверждает допустимое подключение,
точность или полосу входа. Настройка и калибровка входа — отдельный этап.

НАСТРОЙКИ И ВАШИ ФАЙЛЫ

Пользовательское имя CH1 сохраняется отдельно от папки программы в настройках
текущей учётной записи Windows через Qt QSettings (MotortesterV2/Desktop).
Перенос папки программы сам по себе не переносит эти настройки другому
пользователю. Открытая запись использует сохранённое в ней имя и профиль.

Программа сохраняет записи и экспорт в выбранные вами папки. Данные в памяти
автоматически не становятся файлом: сохраняйте нужные записи перед закрытием.

ЧТЕНИЕ БЕЗ ОКНА — НЕОБЯЗАТЕЛЬНО

Откройте PowerShell в папке MotortesterV2. Укажите существующий файл записи,
при необходимости с полным путём:

.\MotortesterV2Inspect.exe "запись.mtv2"
.\MotortesterV2Inspect.exe "запись.mtv2" --csv "анализ.csv"
.\MotortesterV2Inspect.exe "запись.mtv2" --start-index 10000 --stop-index 20000 --csv "участок.csv"

Границы — индексы исходных отсчётов, правая граница не включается.
Команда выводит сведения в JSON и не перезаписывает существующий экспорт.

СОСТАВ И ПРОИСХОЖДЕНИЕ

build-manifest.json описывает исходную версию и сборку. LICENSE, licenses/
и LICENSE-REVIEW.md сохраняют лицензии, уведомления и открытые вопросы аудита
сторонних компонентов. Сборка этого кандидата не означает, что все вопросы
соответствующих исходников библиотек и условий публичного выпуска закрыты.

Комплект сборки включает рядом с ZIP программы source.zip, SHA256SUMS.txt
и журналы сборки. source.zip содержит материалы приложения и не заменяет
полный соответствующий исходный код всех сторонних библиотек.
